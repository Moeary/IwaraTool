# IwaraTool v0.8.1

这是一个包含订阅封面缓存、搜索历史修复和 Windows 窗口抖动修复的维护版本。

## 自 v0.8.0 后的功能更新

- **订阅封面本地缓存**：订阅页的视频封面使用独立的 `data/img/sub/` 缓存目录，并可复用下载历史中的本地封面；缺少封面地址时会从视频详情补全并保存。刷新订阅列表不会再用空地址覆盖已有地址。
- **批量缓存作者封面**：在“刷新操作”中新增“缓存当前订阅源全部封面”，覆盖该源已收录的视频，不受当前筛选影响；已有文件直接复用，失败项会统计并可再次重试。
- **搜索历史兼容性**：兼容旧版本保存的单条历史对象，点击历史记录会恢复数据源、范围、排序和关键词并重新执行搜索；历史弹窗不会抢走输入框焦点。
- **Windows 标题栏拖动**：标题栏拖动改为单次启动系统移动操作，避免鼠标移动事件重复触发拖动。

## Debug 修复

- **修复窗口拖动回弹**：在 175% 等分数 DPI、可用屏幕高度较小的环境中，隐藏的“修复中心”长表单会把主窗口的最小高度撑到屏幕可用高度以上。Windows 会先限制窗口尺寸，Qt 布局随后又尝试恢复原尺寸，拖动时因此出现抖动、跟手性差和位置回弹。
- **修复修复中心布局**：将修复中心的控制面板放入可滚动区域，降低主窗口的最小高度约束；长表单仍可完整访问，不再影响其他页面和窗口拖动。
- **保留高 DPI 兼容性**：不要求用户修改 Windows 显示缩放设置；在 175% 缩放环境下，窗口尺寸在拖动期间保持稳定。

- 运行修复页、窗口布局和标题栏拖动相关测试，确认通过。
