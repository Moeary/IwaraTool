# IwaraTool v1.1.5

本次更新修复 macOS 打包版在用户机器上启动即崩溃的问题，改为提供带拖拽安装指引的 DMG；代理默认关闭并跟随系统代理，预填地址改为 Clash Verge Rev 的 `7897`；搜索页新增“后筛选”，并补充三语安装与上手教程。

## macOS 适配

- 修复启动崩溃：此前打包版仍引用构建机上的 Python 动态库（`/Users/runner/work/.../libpython3.11.dylib`），在用户的 Mac 上无法加载。现在打包时会把所有指向构建环境的库引用改写为应用包内路径，并重新签名。
- 构建流程新增检查：逐个审查 `.app` 中每个 Mach-O 文件的库引用，启动时确认没有任何库从构建环境加载，并在挂载后的 DMG 中再启动验证一次；任一检查失败都会中止发布。
- 新增 DMG 安装包：Apple Silicon 与 Intel 各一个，安装窗口带背景图、箭头和“拖到 Applications”的指引，并提示首次打开被拦截时的处理方法。ZIP 仍然保留。
- 发布文件名改为 `AppleSilicon-ARM64` / `Intel-x86_64`，与“关于本机”中显示的芯片对应。

## 代理默认值

- “登录/解析代理”与“视频下载代理”默认关闭，此时请求跟随系统代理或 TUN；开启代理软件的系统代理即可直接使用。
- 预填地址统一为 `http://127.0.0.1:7897`（Clash Verge Rev 默认端口），可填写任意端口，旧版 CFW 常用的 `7890` 依然可用。
- 从旧版本升级的用户保留原有代理设置，不受新默认值影响。

## 搜索后筛选

- Iwara 搜索接口无法在搜索前限定点赞、时长等条件，搜索页新增“筛选”按钮：在弹窗中设置点赞 / 播放 / 时长范围、发布时间、最低点赞率与排除标签，并可按点赞、播放、点赞率、时长或发布时间重新排序。
- 按钮位于原有的类型 / 排序 / 分级一行，不占用额外的界面高度；筛选只作用于当前页已加载的结果，翻页后继续生效，状态栏显示筛选后的数量。

## 文档

- 新增三语《安装与上手》（`docs/guide/install*.md`）：架构选择、DMG 安装、首次启动的系统安全提示、代理配置、基本使用流程与常见问题。
- 使用指南补充“搜索后筛选”一节。

## 下载

- Windows AMD64：`IwaraTool-Windows-AMD64-v1.1.5.exe`。
- Linux AMD64：`IwaraTool-Linux-AMD64-v1.1.5`。
- macOS Apple Silicon：`IwaraTool-macOS-AppleSilicon-ARM64-v1.1.5.dmg`（另附同内容的 `.zip`）。
- macOS Intel：`IwaraTool-macOS-Intel-x86_64-v1.1.5.dmg`（另附同内容的 `.zip`）。
- macOS 版未使用 Developer ID 签名与公证，首次打开会被系统拦截，处理方法见 [安装与上手](https://github.com/Moeary/IwaraTool/blob/v1.1.5/docs/guide/install.md#macos首次启动的安全提示)。
- 应用内不提供自动替换更新：请从 Release 页面下载新版本覆盖旧程序，设置、队列与历史都会保留。
- 每个发布包附带 `.sha256` 校验文件。
