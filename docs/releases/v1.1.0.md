# IwaraTool v1.1.0

本次更新汇总 `v1.0.0` 之后的全部改动：下载统一进入工作台待确认列表，历史记录增加封面浏览，详情页支持内嵌播放，并完善搜索、导航、登录与后台线程的稳定性。

## 下载工作台与待确认流程

- 搜索、订阅、首页、作者页、详情页以及工作台的作者 / 播放列表链接统一在后台预检查，随后加入工作台的待确认列表；提示中的“去确认”按钮可直接打开工作台。
- 待确认作品与正式任务共用任务列表，置于列表顶部；新增“待确认”状态筛选，逐行展示可下载、跳过或不可下载的判定、原因与目标路径。
- 确认栏以两行展示统计、清空与确认下载操作，以及批次、可搜索的规则选择器和省略显示的保存路径示例；点击统计数字可筛选作品，切换规则会立即重新检查当前批次。
- 支持按批次确认、清空，或在行操作和右键菜单中确认、放行被跳过的作品、移除选中项；站点不提供文件的作品仍会说明不可下载原因。
- 待确认状态随队列持久化，重启后恢复，确认前不参与下载调度；再次提交相同作品会复用已有待确认任务，避免重复创建。
- 新增“单个视频直接下载”选项，默认开启：单个可下载作品可直接开始；新增订阅自动下载是否需要确认的选项，默认关闭。
- 仅标记规则在确认后于后台记录历史，并按规则处理封面与 NFO。
- 侧栏显示待确认数量。旧版暂存批次文件 `data/pending_downloads.json` 会在启动时迁移到工作台一次，原文件移开保留；旧确认弹窗与暂存卡片退出使用。
- 新增下载原因诊断，可从任务列表右键菜单查看已有文件、历史记录、任务状态、订阅记录、下载规则及站点文件可用性等判定。
- 修复订阅页提交下载时访问已移除的工作线程而导致失败的问题。

## 历史记录与封面

- 历史页新增方格和封面视图，并保留列表视图；可查看最近下载、未观看作品，或按作者浏览。
- 记录观看时间，用于未观看筛选；封面视图支持排序、播放及右键操作。
- 修复历史页视图与范围切换，统一使用搜索页的卡片样式和共享封面大小设置。
- 应用内封面统一从图片缓存读取；下载目录中的封面仅用于填充缓存，减少视图对下载文件布局的依赖。

## 视频播放与点击行为

- 详情页可直接内嵌播放，支持通过按钮以同一播放位置转到独立预览窗口。
- 全屏播放使用覆盖屏幕的无边框窗口；保留窗口最大化 / 全屏前的位置和尺寸，修复任务栏位于左侧时窗口几何漂移。
- 关闭播放器时只释放该播放器使用的代理流，避免影响其他播放会话；完善预览窗口的显示与管理。
- 搜索、订阅与作者结果的单击 / 双击行为可在设置中调整；默认单击选择、双击打开详情，搜索结果按 Enter 也可打开详情。
- Oreno3D 卡片打开详情前会先解析对应的 Iwara ID，完善未解析卡片的导航处理。

## 搜索与导航

- 设置中可选择 Iwara 实时 API 或 Oreno3D 作为主搜索引擎。
- 可开启中文视频关键词自动使用 Oreno3D；下一次不含中文的搜索会回到主搜索引擎，手动指定的数据源会得到保留。
- 完善页面返回历史，恢复此前的页面状态与滚动位置；下载、历史、规则、订阅及搜索页支持保留相关草稿和输入状态。
- 改进搜索状态恢复及首页异步更新时的导航处理，减少后台结果覆盖当前浏览状态的情况。

## 稳定性与界面细节

- 统一后台工作线程生命周期管理，避免运行中的线程被销毁导致进程退出；页面关闭时异步等待线程结束，减少界面阻塞。
- 加强已销毁页面、表格列宽保存及后台信号回调的处理，改善网络任务退出与清理行为。
- 增加缓存登录令牌的过期处理，完善使用已保存令牌的登录流程。
- 订阅总览与订阅作品网格在后台刷新时保留用户滚动意图，避免页面被拉回；搜索网格调整滚轮步进。
- 从终端按 Ctrl+C 时保存队列并安全退出。
- 进一步整理下载工作台布局、确认栏和表格宽度处理。
- 修复待确认栏销毁后延迟回调仍尝试访问控件的问题。
- 窗口在等待后台线程退出时立即撤销其快捷键，停止订阅页后不再响应新增订阅信号，避免语言切换或关闭过程中重复注册与重复刷新。

## 内部维护与回归覆盖

- 将搜索、订阅、设置、下载、历史、首页、媒体详情、规则、修复、播放器与主窗口拆分为按职责组织的 UI 模块。
- 将下载调度与传输、Iwara API、订阅存储与刷新、修复、搜索和 Oreno3D 客户端拆分为核心包；将大型函数拆为可单独维护的步骤。
- 同步调整包内资源定位、页面依赖代理与测试导入；整理 NFO、封面缓存、快捷键目录及标签爬取辅助函数。
- 移除未使用的 TaskCard、旧确认流程及订阅入队线程；扩充导航恢复、播放器、点击行为、登录、下载诊断、待确认队列与订阅下载回归覆盖，并改善订阅滚动测试在繁忙环境中的等待处理。
- 应用版本与 Pixi 工作区版本统一为 `1.1.0`。

## 下载与升级

- 新增 macOS Apple Silicon（ARM64）与 Intel（AMD64）原生 `.app` 构建，分别在 macOS 15 CI 上运行测试、打包，并以 ZIP 发布。
- macOS 配置、队列、数据库、规则与缓存保存于 `~/Library/Application Support/IwaraTool/`，默认下载目录为 `~/Downloads/IwaraTool/`；启动前的备份恢复也使用相同位置，不向 `.app` 内写入运行数据。
- macOS 使用系统 `open` 启动本地视频，更新检查按本机架构选择发布包；通过 Release 页面下载并替换应用。自动替换更新与登录自启动仍仅支持 Windows。
- macOS 使用原生 Cocoa 窗口后端验证无边框界面；流式布局统一按控件实际矩形对齐，修正原生按钮样式边距带来的错位。界面回归测试按实际焦点和定时器状态等待，并使用不受 CI 屏幕宽度限制的布局容器。
- Windows AMD64：`IwaraTool-Windows-AMD64-v1.1.0.exe`。
- Linux AMD64：`IwaraTool-Linux-AMD64-v1.1.0`。
- macOS：`IwaraTool-macOS-ARM64-v1.1.0.zip` / `IwaraTool-macOS-AMD64-v1.1.0.zip`。解压后将 `IwaraTool.app` 拖入“应用程序”。未使用 Developer ID 签名与公证；若系统阻止打开，请按“隐私与安全性”的提示允许该应用。更旧的 macOS 版本尚未验证。
- 全部平台的构建均先运行测试，再使用 Nuitka 打包；macOS 打包后另检查 Qt 多媒体后端和内置资源。每个发布包附带 `.sha256` 校验文件。
- 发布流程等待四个构建全部成功后统一上传资产并写入本说明，避免平台任务各自创建不完整的 Release。
- Linux 预编译包基于 GitHub 的 `ubuntu-latest`，较旧 glibc 系统建议使用源码在本机编译。
