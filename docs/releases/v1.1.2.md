# IwaraTool v1.1.2

本次更新修复修复中心在文件较多的文件夹中扫描或修复时界面无响应、操作延迟极高的问题（[#22](https://github.com/Moeary/IwaraTool/issues/22)）。

## 修复中心：大文件夹不再卡死

- 扫描匹配算法重写：已知 Iwara ID 改为按文件名分词查表，标题模糊匹配先按长度、字符计数和二元组上界剪枝，只对可能达到阈值的本地记录计算相似度。判定规则不变；600 个文件对 1500 条本地记录的扫描由约 3 分钟缩短到 1 秒以内。
- 默认命名 `{YYYY-MM-DD}_{title}_{id}` 中以下划线相连的视频 ID 现在可直接识别为已知 ID，不再误判为“待确认”或依赖模糊匹配。
- 扫描结果每 0.2 秒分批实时显示在修复列表中，无需等待全部完成；修复过程同样分批更新进度。
- 修改命名模板、模式、输出目录或附属文件选项后，目标路径预览与冲突检查改在后台线程进行，连续输入会合并为一次计算。
- 修复列表只重绘内容有变化的行；后台扫描线程不再与界面线程争抢翻译设置的锁，本地匹配计算串行进行，网络查询仍并发，避免界面线程长时间拿不到 GIL。
- 列出视频文件改用目录项自带的类型与大小信息，网络盘和大目录少一次逐文件查询。

## 下载

- Windows AMD64：`IwaraTool-Windows-AMD64-v1.1.2.exe`。
- Linux AMD64：`IwaraTool-Linux-AMD64-v1.1.2`。
- macOS：`IwaraTool-macOS-ARM64-v1.1.2.zip` / `IwaraTool-macOS-AMD64-v1.1.2.zip`。未使用 Developer ID 签名与公证；若系统阻止打开，请按“隐私与安全性”的提示允许该应用。
- 应用内不提供自动替换更新：请从 Release 页面下载新版本，覆盖旧程序即可，程序旁的 `data` 目录会保留全部设置、队列与历史。
- 每个发布包附带 `.sha256` 校验文件。
