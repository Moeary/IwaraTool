# IwaraTool v1.0.0

首个正式版。首页、订阅页、搜索页、详情页和快捷键都经过重做，并系统地降低了卡顿和内存占用。

## 首页

- **栏目可自定义**：默认依次为“我的订阅”“热门视频”“热门图片”；可在首页标题栏的铅笔图标（Ctrl+E）或“设置 → 首页”中增删、排序、隐藏栏目，也可把标签搜索（如 hmv）、关键词搜索、某位作者的最新作品放上首页。
- **本地缓存**：每个栏目、标签页和内容分级各自缓存在本地，打开页面即时显示；只有超过设定时间（默认 15 分钟）才在后台重新检查，且仅在帖子真的变化时才更新卡片。
- 加载占位卡片、封面淡入、悬停放大、栏目可折叠、各栏显示更新时间并可单独刷新；失败时保留已有内容并提供重试。
- 首页、搜索页、订阅页共用同一个“封面大小”滑块。

## 订阅页与作者页

- 订阅总览改为整页大列表，点进订阅后的封面不再排在总览封面之后，失败的封面会重试。
- 新增程序内作者页：显示作者是否已在程序内订阅、是否已在 Iwara 关注，可直接订阅或关注。搜索结果、首页卡片、详情页、订阅页都能打开。
- 详情页新增点赞按钮；播放区拉宽，相关推荐在宽窗口移到右侧。

## 键盘

- 新增约 33 个快捷键（Ctrl+K 快速搜索、Ctrl+Tab 切页、Ctrl+Alt+V 粘贴链接下载、Ctrl+Shift+R 切换内容分级等），F1 查看全部，均可在设置中修改。
- 封面网格支持方向键、Enter、Space、Ctrl+A、Esc 和菜单键。

## 性能与内存

- 首页新增一栏的耗时约 157 ms → 19–30 ms；订阅页首次进入约 1.4 s → 0.3 s；历史页 3000 条记录的筛选约 0.85 s → 0.16 s。
- 设置写盘去重，规则选择器不再反复写 `config.ini`。
- 启动内存约 219 MB → 155 MB；大搜索结果和图片作品的峰值内存降低约 65%。最小化或隐藏到托盘后会释放闲置内存。
