# IwaraTool v1.1.4

本次更新为命名规则新增“逐字段拼装”的文件名模板构建器与 26 个预设，修复中心也可直接套用命名预设，并精简三语 README，将技术细节移入参考文档。

## 文件名模板构建器

- 规则编辑页新增模板构建器：逐个选择字段（作者、标题、ID、日期、画质等），再填写字段之间的文字（`_`、`-`、空格，或用 `/` 进入下一级文件夹），即可拼出命名规则；带实时预览，完整规则仍可手动编辑。
- 内置 26 个命名预设，可一键套用后再微调。
- 规则编辑页现在列出全部可用占位符，不必再翻文档。

## 修复中心

- 修复中心新增命名预设，可直接按预设重新整理已有文件的命名。

## 文档

- readme（中 / 英 / 日）只保留面向用户的功能介绍；平台说明、链接类型、命名占位符、内部机制与构建方式移至 `docs/guide/reference*.md`。

## 下载

- Windows AMD64：`IwaraTool-Windows-AMD64-v1.1.4.exe`。
- Linux AMD64：`IwaraTool-Linux-AMD64-v1.1.4`。
- macOS：`IwaraTool-macOS-ARM64-v1.1.4.zip` / `IwaraTool-macOS-AMD64-v1.1.4.zip`。未使用 Developer ID 签名与公证；若系统阻止打开，请按“隐私与安全性”的提示允许该应用。
- 应用内不提供自动替换更新：请从 Release 页面下载新版本，覆盖旧程序即可，程序旁的 `data` 目录会保留全部设置、队列与历史。
- 每个发布包附带 `.sha256` 校验文件。
