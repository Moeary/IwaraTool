# IwaraTool v1.3.0

本次换用全新界面：桌面版改用 Flet 重写的界面，并首次提供 Android 版。原来的 PySide6 界面改名为“经典版”（Classic），本版本继续提供，下个版本起不再提供。

## 新界面

- 启动更快、日常占用内存更少，下载时界面更流畅（对比数据见 [P9 对比](https://github.com/Moeary/IwaraTool/blob/main/docs/verification/flet/P9/README.md)）。
- 窗口宽窄自适应：宽屏为侧栏，较窄时为导航栏，手机为底栏；首页、搜索、订阅、作者页共用同一种视频卡片。
- 资料库重新整理：表格 / 列表 / 封面三种视图，范围与作者筛选，记录面板，可撤销的删除。
- 修复中心改为分步流程，扫描结果逐批显示，扫描后可改选项重新规划。
- 设置修改后立即保存。
- 系统通知：下载完成或失败时合并为一条通知；窗口在前台时显示在应用内。
- Windows 托盘图标与关闭到托盘；macOS 关闭窗口时最小化到程序坞继续运行（设置 → 系统与维护 → 窗口与启动）。
- 开机自动启动。

## 从经典版换到新版

- 两个版本的数据分开保存，互不影响。新版第一次启动时如果发现经典版的数据（macOS 自动查找），会提示导入；之后也可在“设置 → 系统与维护 → 备份与日志 → 从经典版导入…”中导入（Windows 选择经典版所在的文件夹或其中的 `data` 文件夹）。
- 导入的内容有设置、下载历史、下载队列、下载规则和订阅，重启后生效；密码与登录状态不会导入，请重新登录。
- 两个版本的开机自启是各自独立的：如果经典版开着开机自启，请先在经典版里关掉，再在新版里打开。

## 与经典版的差异

- 不能把文件拖进修复中心或工具页，请用按钮选择。
- 不支持鼠标侧键与多段组合快捷键；下载页暂不能逐行多选（批量操作在页头“更多”菜单）。
- 字体设置改为输入字体名称。
- Linux 和 macOS Intel 暂无新版，请继续使用经典版。

## Android（首次提供）

- 浏览、搜索、订阅、下载与播放；修复中心、工具和打开文件夹等桌面功能在手机上隐藏。
- 下载的文件保存在 `Android/data/io.github.moeary.iwaratool/files/Downloads`（文件管理器可见，卸载应用时一并删除）。
- 推荐在设置中使用另一台设备（如 NAS）上的 aria2：手机只负责浏览和提交，文件由那台设备下载，不受手机后台限制。
- 回到应用时，如果剪贴板里有刚复制的 Iwara 作品或作者链接，会提示打开。
- 安装时需要允许“安装未知应用”。

## 下载

- Windows AMD64：`IwaraTool-Windows-AMD64-v1.3.0.zip`（解压后运行 `IwaraTool.exe`）。
- macOS Apple Silicon：`IwaraTool-macOS-AppleSilicon-ARM64-v1.3.0.zip`（解压得到 `IwaraTool.app`）。
- Android：`IwaraTool-Android-v1.3.0.apk`。
- 经典版（本版本后不再提供）：`IwaraTool-Classic-Windows-AMD64-v1.3.0.exe`、`IwaraTool-Classic-Linux-AMD64-v1.3.0`、`IwaraTool-Classic-macOS-AppleSilicon-ARM64-v1.3.0.dmg`、`IwaraTool-Classic-macOS-Intel-x86_64-v1.3.0.dmg`（macOS 另附同内容的 `.zip`）。
- 应用内不提供自动替换更新：请从 Release 页面下载新版本。
