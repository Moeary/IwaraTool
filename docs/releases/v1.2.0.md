# IwaraTool v1.2.0

本次更新新增“工具”页（上传压缩与封面预览）、支持 iwara.ai 并可随时与 iwara.tv 切换，“返回”改为每个页面各自记录，并让 macOS 的快捷键与触控板操作符合系统习惯。

## 工具页

- 侧栏底部新增“工具”页（Ctrl+9），位于“下载规则”与“应用设置”之间；左侧选工具，右侧使用。两个工具都调用 ffmpeg：路径留空时自动在 PATH 和常见安装位置（Homebrew、winget、scoop、Chocolatey、程序所在目录）查找，也可在“应用设置 → 工具”中手动指定。
- **上传压缩**：把视频压到 Iwara 的 300 / 600MB 上传上限以内，输出 H.264 + AAC 的 MP4，分辨率不低于 720p。已符合要求的文件直接沿用或仅重新封装；需要重新编码时使用 x264 两遍编码，也可选用硬件编码器（VideoToolbox / NVENC / QSV / AMF）。结果超出上限时自动降低码率重试，输出为 `原文件名_iwara.mp4`。
- **封面预览**：上传前查看 Iwara 将给出的 16 张封面截图，可切换 3:2 裁切、用方向键逐张查看、保存所选帧或复制时间码；压缩完成后可一键预览结果的封面。

## iwara.tv 与 iwara.ai

- 侧栏底部的地球图标、快捷键 Ctrl+Shift+S（Mac 上 ⌘⇧S）或“应用设置 → 账号与网络 → 站点”可切换浏览的站点，默认 iwara.tv；两站共用同一个账号。
- 切换后首页、搜索与“查看更多”列表改为浏览新站点，首页两站分别缓存。Oreno3D 只收录 iwara.tv，因此在 iwara.ai 下置灰不可选，中文关键词也不再转到 Oreno3D。
- 粘贴的链接始终按自身域名处理：浏览 iwara.tv 时粘贴 iwara.ai 的视频、作者或播放列表链接，同样会到 iwara.ai 获取并下载，反之亦然。
- 订阅源会记住添加时所在的站点（已有订阅都属于 iwara.tv），同一位作者可在两站分别订阅；订阅页只列出当前站点的订阅，后台定时刷新则让每个订阅在各自站点检查。
- 切换前已显示的作品（打开中的详情页、订阅与历史条目、下载任务）仍按原站点打开、播放、点赞与下载。

## 返回与导航

- “返回”（左上角按钮、Esc、鼠标侧键）改为每个页面各自记录：在首页打开作品后去搜索页再回来，返回仍回到首页列表，不会再跳到搜索页。侧栏与 Ctrl+1… 只是切换页面；从其他页面跳转过来的（如“查看详情”、作者页），返回会回到跳转前的页面。
- 打开对话框时按 Esc 会关闭对话框，而不是在其背后执行返回。

## 历史记录

- “按作者”的作者列表可切换按作品数或按作者名排序（中文按拼音），选择会被记住。

## macOS

- 快捷键遵循 Mac 习惯：⌘, 打开设置、⌃Tab 切换页面、⌘R 刷新、⌘[ / ⌘] 返回与翻页、⌘↑ / ⌘↓ 回到顶部 / 底部、⌘⌫ 删除记录、⌃⌘F 全屏、⌘/ 显示快捷键、⌘W 关闭窗口、⌘M 最小化；快捷键一览与设置页直接显示 ⌘ ⌥ ⌃ ⇧ 符号。
- 触控板双指向右轻扫即可返回（指针下的内容能横向滚动时不触发）。
- 修复在帖子页播放视频后，再弹出的对话框无法点击的问题。
- 所有平台都可以用 Ctrl+, 打开设置（Ctrl+8 继续可用）。

## 下载

- Windows AMD64：`IwaraTool-Windows-AMD64-v1.2.0.exe`。
- Linux AMD64：`IwaraTool-Linux-AMD64-v1.2.0`。
- macOS Apple Silicon：`IwaraTool-macOS-AppleSilicon-ARM64-v1.2.0.dmg`（另附同内容的 `.zip`）。
- macOS Intel：`IwaraTool-macOS-Intel-x86_64-v1.2.0.dmg`（另附同内容的 `.zip`）。
- macOS 版未使用 Developer ID 签名与公证，首次打开会被系统拦截，处理方法见 [安装与上手](https://github.com/Moeary/IwaraTool/blob/v1.2.0/docs/guide/install.md#macos首次启动的安全提示)。
- 应用内不提供自动替换更新：请从 Release 页面下载新版本覆盖旧程序，设置、队列与历史都会保留。订阅数据库会自动升级以记录站点；升级后若退回旧版本，添加新订阅会失败。
