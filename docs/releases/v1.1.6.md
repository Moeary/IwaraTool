# IwaraTool v1.1.6

本次更新新增界面字体设置：默认按平台与界面语言自适应选择系统字体，也可指定任意已安装字体，缺字时自动回退；同时修复搜索历史下拉在切回窗口或返回搜索页时自行弹出的问题。

## 界面字体

- “应用设置 → 通用”新增“字体”卡片，默认“自动”：Windows 使用 Segoe UI + 微软雅黑 UI，macOS 使用系统字体 + 苹方，Linux 使用 Noto Sans 系列；日文界面优先日文字体，避免汉字显示为中文字形。
- 可通过“选择字体…”在可搜索的列表中挑选本机已安装的字体，每个字体以自身样式显示并带实时预览。所选字体缺少的字符（如中文、日文）会依次回退到平台字体与系统默认字体。
- 卡片显示当前生效的字体顺序；更改后窗口自动重新载入，当前页面与输入内容会保留。所选字体在本机不存在时自动改用“自动”。
- macOS 不再请求不存在的 Windows 字体（Segoe UI / Microsoft YaHei），日志中的 `missing font family "Segoe UI"` 警告及随之而来的字体别名查找耗时一并消除。
- 下载页与修复中心的日志面板改用各平台的等宽字体（Windows：Cascadia Mono / Consolas，macOS：SF Mono / Menlo）。

## 搜索历史

- 修复搜索历史下拉在切回窗口（Alt+Tab / Cmd+Tab）或从其他页面返回搜索页时自行弹出的问题。此问题自 v0.8.0 起在 Windows 与 macOS 上均存在，现在只有点击关键词框、Tab 切入或快捷键聚焦时才会弹出。
- 快速搜索 `Ctrl+K` 在关键词框已有焦点时也会打开搜索历史；搜索页的 `Ctrl+F` 与 `Ctrl+K` 行为一致，搜索控件折叠时会先展开。

## 其他

- macOS 本地运行 `pixi run test` 时固定使用 cocoa 平台，与 CI 一致。

## 下载

- Windows AMD64：`IwaraTool-Windows-AMD64-v1.1.6.exe`。
- Linux AMD64：`IwaraTool-Linux-AMD64-v1.1.6`。
- macOS Apple Silicon：`IwaraTool-macOS-AppleSilicon-ARM64-v1.1.6.dmg`（另附同内容的 `.zip`）。
- macOS Intel：`IwaraTool-macOS-Intel-x86_64-v1.1.6.dmg`（另附同内容的 `.zip`）。
- macOS 版未使用 Developer ID 签名与公证，首次打开会被系统拦截，处理方法见 [安装与上手](https://github.com/Moeary/IwaraTool/blob/v1.1.6/docs/guide/install.md#macos首次启动的安全提示)。
- 应用内不提供自动替换更新：请从 Release 页面下载新版本覆盖旧程序，设置、队列与历史都会保留。
- 每个发布包附带 `.sha256` 校验文件。
