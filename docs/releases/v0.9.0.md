# IwaraTool v0.9.0

这是 v0.9.0 预发布版本（pre-release），集中改进搜索、作者导航和本地修复，修正 Iwara 关键词检索，以及 Oreno3D 原视频失效后无法继续寻找作者的问题。

## 搜索与作者

- **关键词与标签分开搜索**：Iwara 关键词使用 `/search` 文本索引，标签使用 `/videos` 的 `tags` 参数；两种模式分别保存输入与排序。修复关键词被忽略、结果类似列表首页的问题。
- **服务器排序与分页**：关键词支持相关度、最新、播放数和点赞数，保留服务器返回顺序；标签支持多个标签同时匹配。歧义译名需选择明确的标签 ID，避免静默选错。
- **Oreno3D 部分记录解析**：允许旧收录标题为空，保留仍有效的视频与作者链接；同时识别封面播放入口和观看按钮，限定 Iwara 域名，避免误取无关链接。
- **原视频失效后的作者回退**：在自动补全模式下，Iwara 详情不可用或未提供账号时，从 Oreno3D 作者页检查最多 8 条作品，尝试取得可验证的 Iwara 账号。同一批结果中的同一作者复用一次回退查询。按需模式仍可通过作者操作触发解析。
- **保留来源与已取得的资料**：作者链接独立于视频详情保存；迟到的仅 ID 响应或失败响应不再清除已加载的作者状态。临时 Oreno3D 网络故障可有限重试，终止错误保留原因。
- **作者操作**：可查看作者作品，或订阅并跳转到对应订阅源；搜索结果显示本地已下载、文件已移动、未下载和待识别状态。

## 修复中心

- 默认在原位置重命名，也可按命名规则整理到输出目录；扫描、预览和执行采用一致的目标路径。
- 展示完整源路径与目标路径，检查视频、封面和 NFO 的冲突，避免覆盖已有文件。
- 改进跨盘移动、失败回滚与历史同步；修正长表单和搜索卡片在实际字体下的布局。

## 验证与边界

- Windows 开发环境全量运行 265 项测试通过，未捕获到 Python 后台线程或 Qt 回调异常；应用版本与 Pixi 工作区版本一致为 `0.9.0`。
- 回归覆盖空标题、缺少视频链接、视频返回 `404`、通过其他作品恢复作者、无可用作品、异步响应乱序，以及作者浏览和订阅跳转。
- 在线抽查新旧 Oreno3D 收录；对三条原视频不可访问的记录，成功恢复视频来源链接、Oreno3D 作者页及可验证的 Iwara 作者。
- 原视频被删除或私有时，保留的来源链接不代表视频仍可下载。如果所检查的作品均不可用，仍保留 Oreno3D 作者页供访问，不根据显示名称猜测 Iwara 账号。
