# IwaraTool v1.2.1

本次更新可以把视频交给 NAS / 远端服务器上的 aria2 下载，并统一了各页面的右键菜单（[#28](https://github.com/Moeary/IwaraTool/issues/28)）。

## 下载到 NAS / 远端服务器（aria2）

- “应用设置 → 下载 → aria2”新增“aria2 运行在其他设备上（NAS / 服务器）”。填写 aria2 设备上的下载目录后，视频按下载规则的文件名模板由远端 aria2 直接保存，不会写入本机下载目录；提交失败时任务直接失败，不会悄悄回退到内置下载器把文件存到本机。
- 可选填写该目录在本机的挂载路径（SMB / NFS）：填写后可在本机打开文件夹、用设置中的播放器播放，封面和 NFO 也会写到视频旁边。
- 可选填写该目录的 HTTP 访问地址：没有挂载时，可用内置播放器或自定义播放器命令（如 mpv）串流播放远端文件。
- 历史记录新增“远端”状态，与“正常”“已移走”分开：只因曾下载到 NAS，不会被当成本机文件；“清理失效记录”“同步下载文件夹”“还原已移走”都不会动这些记录。搜索页显示“已下载到远端”，订阅页显示“已存远端”，下载工作台的预检也会说明“已下载到远端”。
- 远端模式下，已在远端的视频会被跳过；切回本地下载后，远端记录不会阻止在本机再下一份。
- 封面始终缓存在本机，历史、订阅与搜索页直接显示，不依赖 NAS 是否在线；未挂载时 NFO 跳过，封面交由远端 aria2 保存到视频旁边。
- 设置中的“测试连接”会检查 aria2 是否可达，以及挂载路径是否可用。

## 统一的右键菜单

- 首页、搜索、订阅（总览与经典表格）、作者页、历史记录和下载工作台的视频菜单使用同一顺序：查看详情 → 播放 → 打开所在文件夹 / 复制文件路径 → 下载 → 在浏览器打开 / 复制链接 → 作者相关 → 本页管理项。
- “播放”按文件位置显示为“播放本地文件”“播放远端文件”或“在线播放”；作者页与历史记录也能“打开所在文件夹”，各页都新增“复制链接”与“复制文件路径”。
- 修正菜单里偶尔出现连续两条分隔线的问题。

## 下载

- Windows AMD64：`IwaraTool-Windows-AMD64-v1.2.1.exe`。
- Linux AMD64：`IwaraTool-Linux-AMD64-v1.2.1`。
- macOS Apple Silicon：`IwaraTool-macOS-AppleSilicon-ARM64-v1.2.1.dmg`（另附同内容的 `.zip`）。
- macOS Intel：`IwaraTool-macOS-Intel-x86_64-v1.2.1.dmg`（另附同内容的 `.zip`）。
- 应用内不提供自动替换更新：请从 Release 页面下载新版本覆盖旧程序，设置、队列与历史都会保留。历史数据库会自动增加“存储位置”字段，旧记录均视为本地下载。
