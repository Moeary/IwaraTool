# IwaraTool v1.2.3

本次为修复版：修复中心能识别更多浏览器下载的视频文件名，识别不到的视频可以在修复列表里手动填写 Iwara ID（[#32](https://github.com/Moeary/IwaraTool/issues/32)）。

## 文件名识别

- 支持 `Iwara - 标题 [视频ID] [Source].mp4` 这类浏览器 / yt-dlp 风格的文件名：方括号、圆括号、花括号或【】中的视频 ID 会被识别。
- 不再把 `Iwara - ` 后面的第一个词（如 `SEXDance`、`TimeStop`）当成视频 ID，这类文件以前会报“作品不存在或当前账号不可见”。只有带 `id` 标记（如 `iwara-id=…`、`Iwara ID …`、`video_id: …`）或 Iwara 视频链接中的 ID 才会被直接采用。
- 没有标记的 ID 候选（括号中的 ID、规则命名末尾的 `_{id}`、文件名里其他像 ID 的片段）会先经 Iwara 确认；确认不了就依次尝试下一个候选，最多 3 个，之后再按标题搜索。
- 按标题搜索时会去掉 `Iwara - ` 前缀、`[Source]` / `[1080p]` 等画质标记和 ID 片段，搜索词更接近原标题。

## 手动填写 Iwara ID

- 修复列表中“跳过”“待确认”等未完成的行，可双击“Iwara ID”列，填写视频 ID 或 `https://www.iwara.tv/video/<id>` 链接，按回车后会按该 ID 重新查询并生成目标路径，同时重新检查与其他文件的冲突。
- 已识别但匹配错误的行也可以这样改正；已完成的行不可修改。扫描或修复进行中暂不能编辑。
- 填写的内容不是有效 ID 或链接时会提示并还原；查询不到该视频时该行保持“跳过”，详情中显示原因。

- Linux AMD64：`IwaraTool-Linux-AMD64-v1.2.3`。
- macOS Apple Silicon：`IwaraTool-macOS-AppleSilicon-ARM64-v1.2.3.dmg`（另附同内容的 `.zip`）。
- macOS Intel：`IwaraTool-macOS-Intel-x86_64-v1.2.3.dmg`（另附同内容的 `.zip`）。
- 应用内不提供自动替换更新：请从 Release 页面下载新版本覆盖旧程序，设置、队列与历史都会保留。
