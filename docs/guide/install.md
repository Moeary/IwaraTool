# 安装与上手

[English](./install_en.md) | [日本語](./install_ja.md) | [返回 README](../readme/readme_zh.md)

本文说明如何选择安装包、在各平台安装、处理 macOS 首次启动的安全提示、配置代理，以及最基本的使用流程。

## 选择安装包

在 [Releases](https://github.com/Moeary/IwaraTool/releases) 中按系统下载：

| 系统 | 文件 | 说明 |
| --- | --- | --- |
| Windows 10 / 11（64 位） | `IwaraTool-Windows-AMD64-v<版本>.zip` | 解压后运行 `IwaraTool.exe` |
| macOS · Apple Silicon（M 系列芯片） | `IwaraTool-macOS-AppleSilicon-ARM64-v<版本>.zip` | 解压得到 `IwaraTool.app` |
| Android | `IwaraTool-Android-arm64-v8a-v<版本>.apk`（推荐） | 按设备架构选择，见下文；安装时需允许“安装未知应用” |

Linux 与 Intel 芯片的 Mac 暂无预编译包，可从源码运行（见 [参考文档](./reference.md#从源码运行--构建)），或继续使用 v1.2.3。

**如何确认 Mac 的芯片**：点击屏幕左上角  →“关于本机”。“芯片”一栏写着 **Apple M1 / M2 / M3 / M4…** 即为 Apple Silicon。CI 在 macOS 15 上验证，更旧的系统版本尚未验证。

## macOS：安装

1. 双击下载的 `.zip`，解压得到 `IwaraTool.app`。
2. 把 `IwaraTool.app` 拖到“应用程序”文件夹。
3. 从“应用程序”文件夹或启动台打开 IwaraTool。

更新时用新的 `IwaraTool.app` 替换旧的即可；设置、历史记录和订阅都保存在 `~/Library/Application Support/IwaraTool/`，不会因替换应用而丢失。

## Windows：安装与更新

把压缩包解压到任意文件夹并运行 `IwaraTool.exe`。设置与历史保存在程序旁的 `data/` 文件夹：更新时把新版解压到同一文件夹覆盖即可；从 v1.2 及更早版本升级时，也解压到旧版 `.exe` 所在的文件夹（放在别处时，可在“设置 → 存储 → 备份与日志 → 从旧版导入…”中导入）。

Windows 版没有代码签名，首次运行时 SmartScreen 可能提示“Windows 已保护你的电脑”，点“更多信息 → 仍要运行”即可；个别杀毒软件也可能误报，可将程序所在文件夹加入信任。程序由 GitHub Actions 从本仓库源码构建，可自行核对或从源码运行。

## Android：安装与更新

Android 按处理器架构分包，体积更小：

- `arm64-v8a`：近几年的绝大多数手机和平板，**首选**；
- `armeabi-v7a`：较老的 32 位 ARM 设备；
- `x86_64`：模拟器、部分 Chromebook；
- `universal`：包含全部架构、体积最大，不确定设备架构时使用。

应用内检查到新版本时会直接下载适合本机的 APK。安装 `.apk` 时按提示允许“安装未知应用”。所有版本使用同一个签名，之后下载新版 `.apk` 直接安装即可覆盖升级，数据保留。

## macOS：首次启动的安全提示

IwaraTool 没有付费的 Apple Developer ID 签名，也未经 Apple 公证，所以第一次打开时系统会拦截。这是 macOS 对所有未公证应用的统一处理，按下面的方法允许一次即可，之后正常打开。

**macOS 15（Sequoia）及更新版本**

1. 先双击打开一次 IwaraTool，在提示“Apple 无法验证……”的对话框中点“完成”。
2. 打开“系统设置”→“隐私与安全性”，滚动到最下方的“安全性”区域。
3. 在“已阻止使用 IwaraTool，因为来自身份不明的开发者”旁点击 **“仍要打开”**，输入登录密码。
4. 在随后的对话框中再点一次“仍要打开”。

**macOS 14（Sonoma）及更早版本**：在“应用程序”文件夹中按住 Control 键点按 IwaraTool（或右键）→“打开”，再在对话框中点“打开”。

**提示“已损坏，无法打开，你应该将它移到废纸篓”**：通常是浏览器给文件加上的隔离属性所致，并非文件真的损坏。确认文件来自本项目的 Releases 页面后，在“终端”中执行：

```bash
xattr -dr com.apple.quarantine /Applications/IwaraTool.app
```

然后重新打开即可。

## 代理配置

访问 Iwara 通常需要代理。IwaraTool 的“登录/解析代理”和“视频下载代理”**默认都处于关闭状态**，此时请求跟随系统代理或 TUN：

- 代理软件已开启 **系统代理** 或 **TUN 模式**：无需任何设置。
- 两者都没开：打开“设置 → 账号与网络 → 代理”，启用“登录/解析代理”，填写代理软件的本地 HTTP / 混合端口，然后点“应用”。

| 代理软件 | 常见默认地址 |
| --- | --- |
| Clash Verge Rev（预填值） | `http://127.0.0.1:7897` |
| 旧版 Clash for Windows / ClashX 等 | `http://127.0.0.1:7890` |
| 其他软件 | 以软件设置中显示的端口为准，可填写任意端口 |

“视频下载代理”只影响视频文件本身（以及 aria2 的 `all-proxy`），封面、头像和元数据始终跟随“登录/解析代理”。从旧版本升级的用户会保留原来的代理设置，不受新默认值影响。Linux 不会读取桌面环境的系统代理，请在程序内启用代理，或设置 `HTTPS_PROXY` 等环境变量。

## 基本使用流程

1. **登录（可选）**：点侧栏底部的账号入口（手机为右上角头像），或在“设置 → 账号与网络”中登录。下载私有视频、查看“我的订阅”或导入关注的作者时需要登录。
2. **下载**：在“下载”页粘贴作者、播放列表、搜索页或单个视频的链接并点“下载”，在弹出的面板中确认内容和下载规则。未完成的任务下次打开时会继续；下载好的视频在“资料库”中查看和播放。
3. **搜索**：在“搜索”页选择数据源与类型并输入关键词。Iwara 的搜索接口无法预先限定点赞、时长等条件，可在结果出来后点“筛选”按钮，在面板中设置条件并重新排序（详见 [使用指南](./usage.md#搜索后筛选)）。点击封面查看详情和播放；勾选多个结果后点“下载 N 项”即可批量下载。
4. **订阅**：在搜索结果或作者页订阅作者 / 播放列表，之后在“订阅”页查看新作品并只下载新增部分。

更多细节见 [使用指南](./usage.md) 与 [参考文档](./reference.md)。

## 常见问题

**首页或搜索一直加载失败**：多半是网络无法直连 Iwara。确认代理软件正在运行，并按上文开启系统代理 / TUN，或在程序内填写正确端口。Clash Verge Rev 默认是 `7897`，不是旧教程中常见的 `7890`。

**macOS 提示“无法打开”或“已损坏”**：见上文“首次启动的安全提示”。若在 Intel Mac 上打开 ARM64 版，系统会提示不支持此类 Mac，请改下 Intel-x86_64 版。

**数据保存在哪里、如何卸载**：macOS 的设置与缓存位于 `~/Library/Application Support/IwaraTool/`，视频默认下载到 `~/Downloads/IwaraTool/`。卸载时把“应用程序”中的 IwaraTool 移到废纸篓；若不再需要数据，再删除上述数据目录。Windows / Linux 版的数据位于程序旁的 `data/` 文件夹。详见 [本地数据与缓存](./data.md)。

**如何更新**：可在“设置 → 关于”中检查是否有新版本；从 Releases 下载新版本替换旧程序即可，数据会保留（Android 直接安装新版 APK 覆盖升级）。
