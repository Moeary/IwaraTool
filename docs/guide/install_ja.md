# インストールと基本の使い方

[简体中文](./install.md) | [English](./install_en.md) | [README に戻る](../readme/readme_ja.md)

ダウンロードするファイルの選び方、各プラットフォームでのインストール、macOS の初回起動時のセキュリティ警告への対処、プロキシ設定、基本的な使い方を説明します。

## ファイルの選び方

[Releases](https://github.com/Moeary/IwaraTool/releases) からお使いのシステム向けのファイルをダウンロードします。

| システム | ファイル | 備考 |
| --- | --- | --- |
| Windows 10 / 11（64 ビット） | `IwaraTool-Windows-AMD64-v<バージョン>.zip` | 展開して `IwaraTool.exe` を実行 |
| macOS · Apple シリコン（M シリーズ） | `IwaraTool-macOS-AppleSilicon-ARM64-v<バージョン>.zip` | 展開すると `IwaraTool.app` |
| Android | `IwaraTool-Android-v<バージョン>.apk` | インストール時に「不明なアプリのインストール」を許可 |

Linux と Intel Mac 向けのビルド済みパッケージは現在ありません。ソースから実行するか（[リファレンス](./reference_ja.md) 参照）、v1.2.3 を引き続きお使いください。

**Mac のチップの確認方法**：画面左上の  →「この Mac について」を開き、「チップ」が **Apple M1 / M2 / M3 / M4…** なら Apple シリコンです。CI は macOS 15 で検証しており、それより古いバージョンは未検証です。

## macOS：インストール

1. ダウンロードした `.zip` をダブルクリックして `IwaraTool.app` を取り出します。
2. `IwaraTool.app` を「アプリケーション」フォルダへドラッグします。
3. 「アプリケーション」フォルダか Launchpad から IwaraTool を起動します。

更新時は新しい `IwaraTool.app` で置き換えます。設定・履歴・購読は `~/Library/Application Support/IwaraTool/` に保存され、アプリを置き換えても残ります。

## Windows：インストールと更新

任意のフォルダーに展開して `IwaraTool.exe` を実行します。設定と履歴はプログラム横の `data/` フォルダーに保存されるため、更新時は同じフォルダーに新しいバージョンを展開してください。v1.2 以前からの更新も、旧 `.exe` のあるフォルダーに展開します（別の場所に置いた場合は「設定 → ストレージ → バックアップとログ → 旧バージョンから取り込む…」で取り込めます）。

Windows 版にはコード署名がないため、初回実行時に SmartScreen が「Windows によって PC が保護されました」と表示することがあります。「詳細情報 → 実行」を選んでください。一部のウイルス対策ソフトが誤検知することもあるので、その場合はプログラムのフォルダーを除外に追加してください。リリースは GitHub Actions が本リポジトリのソースからビルドしているため、内容を確認したりソースから実行したりできます。

## Android：インストールと更新

`.apk` のインストール時に「不明なアプリのインストール」を許可してください。すべてのリリースが同じ署名を持つため、新しい `.apk` をそのままインストールすれば上書き更新され、データも残ります。

## macOS：初回起動時のセキュリティ警告

IwaraTool は有料の Apple Developer ID 署名と Apple の公証を受けていないため、初回は macOS にブロックされます。公証されていないアプリ共通の動作で、一度許可すれば以後は普通に開けます。

**macOS 15（Sequoia）以降**

1. IwaraTool を一度開き、「Apple は … を検証できませんでした」のダイアログで「完了」をクリックします。
2. 「システム設定」→「プライバシーとセキュリティ」を開き、下部の「セキュリティ」までスクロールします。
3. 「IwaraTool は Mac を保護するためにブロックされました」の横にある **「このまま開く」** をクリックし、ログインパスワードを入力します。
4. 続くダイアログでもう一度「このまま開く」をクリックします。

**macOS 14（Sonoma）以前**：「アプリケーション」で IwaraTool を Control キーを押しながらクリック（または右クリック）→「開く」を選び、ダイアログで「開く」をクリックします。

**「IwaraTool は壊れているため開けません。ゴミ箱に入れる必要があります。」と表示される場合**：多くはブラウザが付けた隔離属性が原因で、実際に壊れているわけではありません。本プロジェクトの Releases から取得したことを確認したうえで、ターミナルで次を実行してください。

```bash
xattr -dr com.apple.quarantine /Applications/IwaraTool.app
```

その後もう一度開きます。

## プロキシ

Iwara への接続には通常プロキシが必要です。IwaraTool の「ログイン/解析プロキシ」と「動画ダウンロードプロキシ」は **既定で無効** で、その間はシステムプロキシまたは TUN に従います。

- プロキシソフトで **システムプロキシ** または **TUN モード** が有効：設定は不要です。
- どちらも無効：「設定 → アカウントとネットワーク → プロキシ」で「ログイン/解析プロキシ」を有効にし、プロキシソフトのローカル HTTP / mixed ポートを入力して「適用」をクリックします。

| プロキシソフト | よくある既定アドレス |
| --- | --- |
| Clash Verge Rev（初期値） | `http://127.0.0.1:7897` |
| 旧 Clash for Windows、ClashX など | `http://127.0.0.1:7890` |
| その他 | ソフトの設定に表示されるポート（任意のポートを入力できます） |

動画ダウンロードプロキシは動画ファイル本体（と aria2 の `all-proxy`）にのみ影響し、サムネイル・アバター・メタデータは常にログイン/解析プロキシに従います。旧バージョンから更新した場合は既存のプロキシ設定が維持されます。Linux はデスクトップのシステムプロキシを読み取らないため、アプリ内でプロキシを有効にするか `HTTPS_PROXY` などの環境変数を設定してください。

## 基本の使い方

1. **ログイン（任意）**：サイドバー下部のアカウント（スマートフォンでは右上のアバター）か「設定 → アカウントとネットワーク」でログインします。非公開動画、ホームの「マイ購読」、フォロー作者の取り込みに必要です。
2. **ダウンロード**：「ダウンロード」ページに作者・プレイリスト・検索・動画の URL を貼り付けて「ダウンロード」を押し、開いたパネルで内容とルールを確認します。未完了のタスクは次回起動時に再開し、保存した動画は「ライブラリ」で確認・再生できます。
3. **検索**：「検索」ページでソースと対象を選び、キーワードを入力します。Iwara の検索 API はいいね数や長さを事前に指定できないため、結果が出たら **「絞り込み」** ボタンを押し、パネルで条件と並び順を設定します（[使用ガイド](./usage_ja.md#検索後の絞り込み) 参照）。カバーをクリックすると詳細と再生、複数の結果を選んで「保存 N」でまとめてダウンロードできます。
4. **購読**：検索結果や作者ページから作者・プレイリストを購読し、「購読」ページで新着だけをダウンロードします。

詳しくは [使用ガイド](./usage_ja.md) と [リファレンス](./reference_ja.md) を参照してください。

## よくある質問

**ホームや検索の読み込みが終わらない**：Iwara に直接接続できていない可能性が高いです。プロキシソフトが起動していることを確認し、システムプロキシ / TUN を有効にするか、アプリに正しいポートを入力してください。Clash Verge Rev の既定は `7897` で、古い解説によくある `7890` ではありません。

**macOS で「開けません」「壊れています」と表示される**：上記の初回起動の項を参照してください。Intel Mac で ARM64 版を開くとこの Mac ではサポートされていない旨が表示されるので、Intel-x86_64 版をダウンロードしてください。

**データの場所とアンインストール**：macOS の設定とキャッシュは `~/Library/Application Support/IwaraTool/`、動画の既定の保存先は `~/Downloads/IwaraTool/` です。アンインストールは「アプリケーション」の IwaraTool をゴミ箱へ移し、不要ならデータフォルダも削除します。Windows / Linux 版はプログラム横の `data/` フォルダにデータを保存します。[ローカルデータとキャッシュ](./data_ja.md) を参照してください。

**更新方法**：「設定 → 情報」で新しいバージョンを確認できます。Releases からダウンロードして古いプログラムと置き換えてください。データは保持されます（Android は新しい APK をそのまま上書きインストール）。
