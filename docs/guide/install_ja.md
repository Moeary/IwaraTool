# インストールと基本の使い方

[简体中文](./install.md) | [English](./install_en.md) | [README に戻る](../../readme_ja.md)

ダウンロードするファイルの選び方、各プラットフォームでのインストール、macOS の初回起動時のセキュリティ警告への対処、プロキシ設定、基本的な使い方を説明します。

## ファイルの選び方

[Releases](https://github.com/Moeary/IwaraTool/releases) からお使いのシステム向けのファイルをダウンロードします。

| システム | ファイル | 備考 |
| --- | --- | --- |
| Windows 10 / 11（64 ビット） | `IwaraTool-Windows-AMD64-<バージョン>.exe` | 単一ファイル。ダブルクリックで起動 |
| Linux（x86_64） | `IwaraTool-Linux-AMD64-<バージョン>` | `ubuntu-latest` でビルド。glibc が古いディストリビューションではソースから実行してください |
| macOS · Apple シリコン（M シリーズ） | `IwaraTool-macOS-AppleSilicon-ARM64-v<バージョン>.dmg` | 推奨 |
| macOS · Intel プロセッサ | `IwaraTool-macOS-Intel-x86_64-v<バージョン>.dmg` | 推奨 |

macOS 版には同じアプリを収めた `.zip` も付いています。すべてのファイルに `.sha256` チェックサムがあります。

**Mac のチップの確認方法**：画面左上の  →「この Mac について」を開きます。「チップ」が **Apple M1 / M2 / M3 / M4…** なら AppleSilicon-ARM64、「プロセッサ … Intel Core …」なら Intel-x86_64 を選んでください。Apple シリコンの Mac は Rosetta で Intel 版も動きますが遅くなります。Intel Mac では ARM64 版は動きません。CI は macOS 15 で検証しており、それより古いバージョンは未検証です。

## macOS：DMG からインストール

1. ダウンロードした `.dmg` をダブルクリックしてインストール画面を開きます。
2. 矢印に従って **IwaraTool** のアイコンを **Applications** フォルダへドラッグします。
3. Finder のサイドバーで「IwaraTool」ディスクを取り出します。その後 `.dmg` は削除して構いません。
4. 「アプリケーション」フォルダか Launchpad から IwaraTool を起動します。DMG の画面から直接起動しないでください（読み取り専用で、更新時に置き換えできません）。

更新時は同じ手順で「置き換える」を選びます。設定・履歴・購読は `~/Library/Application Support/IwaraTool/` に保存され、アプリを置き換えても残ります。

## macOS：初回起動時のセキュリティ警告

IwaraTool は有料の Apple Developer ID 署名と Apple の公証を受けていないため、初回は macOS にブロックされます。公証されていないアプリ共通の動作で、一度許可すれば以後は普通に開けます。

**macOS 15（Sequoia）以降**

1. IwaraTool を一度開き、「Apple は … を検証できませんでした」のダイアログで「完了」をクリックします。
2. 「システム設定」→「プライバシーとセキュリティ」を開き、下部の「セキュリティ」までスクロールします。
3. 「IwaraTool は Mac を保護するためにブロックされました」の横にある **「このまま開く」** をクリックし、ログインパスワードを入力します。
4. 続くダイアログでもう一度「このまま開く」をクリックします。

**macOS 14（Sonoma）以前**：「アプリケーション」で IwaraTool を Control キーを押しながらクリック（または右クリック）→「開く」を選び、ダイアログで「開く」をクリックします。

**「IwaraTool は壊れているため開けません。ゴミ箱に入れる必要があります。」と表示される場合**：多くはブラウザが付けた隔離属性が原因で、実際に壊れているわけではありません。本プロジェクトの Releases から取得したことを確認したうえで、ターミナルで次を実行してください。

```bash
xattr -dr com.apple.quarantine /Applications/IwaraTool.app
```

その後もう一度開きます。

## プロキシ

Iwara への接続には通常プロキシが必要です。IwaraTool の「ログイン/解析プロキシ」と「動画ダウンロードプロキシ」は **既定で無効** で、その間はシステムプロキシまたは TUN に従います。

- プロキシソフトで **システムプロキシ** または **TUN モード** が有効：設定は不要です。
- どちらも無効：「設定 → プロキシ」で「ログイン/解析プロキシ」を有効にし、プロキシソフトのローカル HTTP / mixed ポートを入力して「適用」をクリックします。

| プロキシソフト | よくある既定アドレス |
| --- | --- |
| Clash Verge Rev（初期値） | `http://127.0.0.1:7897` |
| 旧 Clash for Windows、ClashX など | `http://127.0.0.1:7890` |
| その他 | ソフトの設定に表示されるポート（任意のポートを入力できます） |

動画ダウンロードプロキシは動画ファイル本体（と aria2 の `all-proxy`）にのみ影響し、サムネイル・アバター・メタデータは常にログイン/解析プロキシに従います。旧バージョンから更新した場合は既存のプロキシ設定が維持されます。Linux はデスクトップのシステムプロキシを読み取らないため、アプリ内でプロキシを有効にするか `HTTPS_PROXY` などの環境変数を設定してください。

## 基本の使い方

1. **ログイン（任意）**：「設定 → アカウントログイン」でログインします。非公開動画、ホームの「マイ購読」、フォロー作者の取り込みに必要です。
2. **ダウンロード**：「ダウンロードワークベンチ」に作者・プレイリスト・検索・動画の URL を貼り付け、ルールを選んで送信します。未完了のタスクは次回起動時に再開します。
3. **検索**：「検索」ページでソースと対象を選び、キーワードを入力します。Iwara の検索 API はいいね数や長さを事前に指定できないため、結果が出たら **「絞り込み」** ボタンを押し、ポップアップで条件と並び順を設定します（[使用ガイド](./usage_ja.md#検索後の絞り込み) 参照）。結果を選択して「選択を追加」でダウンロードします。
4. **購読**：検索結果や作者ページから作者・プレイリストを購読し、「購読」ページで新着だけをダウンロードします。

詳しくは [使用ガイド](./usage_ja.md) と [リファレンス](./reference_ja.md) を参照してください。

## よくある質問

**ホームや検索の読み込みが終わらない**：Iwara に直接接続できていない可能性が高いです。プロキシソフトが起動していることを確認し、システムプロキシ / TUN を有効にするか、アプリに正しいポートを入力してください。Clash Verge Rev の既定は `7897` で、古い解説によくある `7890` ではありません。

**macOS で「開けません」「壊れています」と表示される**：上記の初回起動の項を参照してください。Intel Mac で ARM64 版を開くとこの Mac ではサポートされていない旨が表示されるので、Intel-x86_64 版をダウンロードしてください。

**データの場所とアンインストール**：macOS の設定とキャッシュは `~/Library/Application Support/IwaraTool/`、動画の既定の保存先は `~/Downloads/IwaraTool/` です。アンインストールは「アプリケーション」の IwaraTool をゴミ箱へ移し、不要ならデータフォルダも削除します。Windows / Linux 版はプログラム横の `data/` フォルダにデータを保存します。[ローカルデータとキャッシュ](./data_ja.md) を参照してください。

**更新方法**：Windows 版は「設定 → GitHub Release 更新」から更新できます。macOS と Linux は新しいバージョンをダウンロードして置き換えてください。データは保持されます。
