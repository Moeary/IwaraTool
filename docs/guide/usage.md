## 首页与内容分级

首页是第一个页面，默认依次展示“最新”“我的订阅”（需要登录；视频或图片）“热门视频”和“热门图片”。每一栏都可以折叠（点击栏目标题），显示“更新于几分钟前”，并有自己的刷新按钮；热门栏可切换趋势、热度、最新。点击标题栏的铅笔图标（Ctrl+E）或进入“应用设置 → 首页”可以自定义栏目：增删、拖动排序、临时隐藏，并把搜索页里能搜到的内容放上首页——例如一栏“标签 hmv · 最新”、某位作者的最新作品、某个关键词的搜索结果，每栏可选视频或图片与排序方式；“恢复默认”可回到初始四栏。各栏的内容缓存在本地并立即显示，只有超过“应用设置 → 首页”中设定的时间（默认 15 分钟，0 表示只在手动刷新时检查）才会在后台重新向网站检查，且仅当帖子真的变化时才更新卡片；切换页面不会触发刷新，正在勾选卡片时有新内容会提示“有新内容，点击显示”而不是打断你。账号订阅流、每个排序标签、每个分级各自独立缓存，登录状态变化时只清除账号相关缓存。单击卡片在应用内打开详情：封面与播放、统计、点赞按钮、作者（作者页、查看作品、订阅状态）、简介、可点击的标签、相关推荐和评论；图片作品直接显示整组图片。热门或自定义栏右侧的“在搜索页查看更多”会跳到搜索页，并带上对应的类型、标签或关键词与排序（作者栏则打开应用内作者页），翻页、列表视图和批量加入队列都在搜索页完成；“我的订阅”的“查看更多”打开分页列表，卡片右上角可勾选，选中后用所选下载规则批量加入队列。每个视频栏也有“下载当前展示”。首页、搜索页、订阅页和“查看更多”列表共用同一个“封面大小”滑块（搜索页原来的“列数”下拉框已并入），可随意放大缩小卡片；加载中显示占位卡片，封面载入时淡入，悬停时轻微放大。右键卡片可播放、下载、打开浏览器、打开作者页、查看作者作品或订阅作者。

右上角的“内容分级”（全部 / SFW / NSFW）同时作用于首页和 Iwara 搜索，选择会保存。`/videos` 与 `/images` 由服务器按 `rating=general|ecchi` 过滤；文本搜索 `/search` 会忽略该参数，因此 SFW / NSFW 时每次取 100 条并在本地过滤，结果不足约 24 条时会继续读取后续页（最多 4 页），“下一页”从读到的最后一页之后继续。Oreno3D 结果没有分级信息，此时选择器隐藏。搜索页的“图片”范围现在可留空关键词直接浏览。右键搜索结果的“查看详情”可在首页详情页打开该作品。侧栏顺序为：首页、订阅页、搜索、下载工作台、修复、历史记录，对应 Ctrl+1 至 Ctrl+6（规则与设置为 Ctrl+7、Ctrl+8，均可在设置中修改）。启动后进入的页面可在“应用设置 → 窗口与启动 → 启动时进入的页面”中选择，默认首页。详情页在宽窗口中会把播放区拉伸到可用宽度，相关推荐移到右侧一栏；从其他页面（如订阅页）打开详情后，“返回”会回到原来的页面。

## 订阅页

订阅页现在只保留作者与播放列表（账号订阅流已由首页的“我的订阅”取代，旧的账号流源不再显示）。默认的“总览”用整页大列表呈现每个订阅：头像、名称、新增 / 未下载数量，以及最近的视频封面条；点击封面进入视频详情，右键封面可查看详情、播放、下载或标记，点击订阅行或“查看全部”则以搜索页那样的网格查看该作者 / 播放列表的全部视频，可筛选状态、搜索标题、勾选后按所选规则批量下载。进入某个订阅时，当前页的封面会立即排到下载队列最前面（不再排在总览里几百个封面之后），状态栏显示“正在加载封面（还剩 n 个）”，下载失败的封面会在再次查看或点“刷新”时重试。标题栏的“经典表格”保留了原来的列表 / 封面双栏视图，其封面视图也使用同一个封面大小滑块。

任务中心顶部新增“总下载速度”，实时汇总所有正在下载任务的速度。

## 作者页、订阅状态与点赞

在搜索结果、首页卡片、详情页或订阅页里选择“打开作者页”，默认会跳到程序内的作者页：已在程序内订阅的作者直接打开其订阅网格，其他作者则显示他们在 Iwara 上的作品（视频 / 图片，可翻页、勾选批量下载）。作者页和订阅网格顶部有两枚状态标签：“已在程序内订阅 / 未在程序内订阅”和“已在 Iwara 关注 / 未在 Iwara 关注 / 未登录”（后者需要登录 Iwara），旁边的按钮可以在程序内订阅或取消订阅，也可以直接在 Iwara 网站上关注或取消关注。详情页的作者卡片也有同样的状态栏，另有“作者页”按钮。无法确定 Iwara 账号的 Oreno3D 结果仍可用“在浏览器打开作者页”访问来源站。

详情页新增“点赞”按钮：登录后可给视频或图片作品点赞，再点一次取消，点赞数即时更新；未登录时会提示先登录。

## 修复中心

批量修改已有视频名称时，在“修复中心”选择文件夹、命名规则并扫描。默认“原地重命名”保留各文件的原目录，只应用规则的文件名部分；需要按 `{author}/` 等目录规则移动文件时，再选择“整理到输出目录”，输出留空则使用扫描根目录。执行前核对列表中的完整原路径和目标路径；冲突项会跳过，已有同名文件不会被覆盖。只需补录下载记录时，可关闭重命名、封面和 NFO，仅保留加入下载历史。

## 搜索下载标记

搜索中的下载标记来自本地历史和文件是否存在：历史文件仍在时为“本地已下载”，路径失效时为“已移走”；Oreno3D 结果取得 Iwara ID 后才判断下载状态。右键查看作者作品无需添加订阅；“加入订阅并前往”会定位该作者的订阅源。

## Oreno3D 作者回退

Oreno3D 原视频已删除或无法访问时，自动补全会通过作者页的其他作品继续寻找 Iwara 作者；按需模式可通过作者操作触发。找不到可验证账号时仍保留 Oreno3D 作者页，不根据显示名称猜测账号。

## Iwara 关键词与标签搜索

Iwara 的“关键词搜索”与“标签搜索”分别保留输入和排序。关键词支持最新、相关度、播放量和点赞数排序，精确短语可加双引号；留空则浏览视频列表。标签可选择中日英候选或输入完整译名，以逗号分隔多个标签，查找同时包含它们的视频。分页和排序由服务器执行，失败原因会保留显示。

## Oreno3D 标签桥接

Oreno3D 标签桥接支持单标签直达 `/tags/{id}`，多个标签会在客户端取交集；也可输入 `tag:<id>`、`origin:<id>`、`character:<id>` 或对应的 Oreno3D 实体 URL。该桥接目前支持 Oreno3D 的视频与标签搜索；作者或播放列表结果请切换到 Iwara 实时 API。结果仍会解析为正式的 Iwara 视频后再打开或加入队列。标签编号可参阅 [标签索引](../iwara_tags.md)。

## 订阅封面缓存

订阅封面会自动保存到本地。需要提前缓存某位作者时，先选择该订阅源并刷新视频列表，再使用“刷新操作 → 缓存当前订阅源全部封面”。此操作覆盖该源已收录的全部视频，不受当前筛选或列表/封面视图影响，不下载视频；再次执行会复用已有封面并重试缺失项。首次取得封面仍需网络可用，完成后会显示成功与失败数量。
