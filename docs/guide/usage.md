# 使用指南

[English](./usage_en.md) | [日本語](./usage_ja.md) | [返回 README](../readme/readme_zh.md)

本文补充 README 快速开始之后的细节说明。

## 界面布局

宽窗口左侧是侧栏：上部是五个主要页面——首页、订阅、搜索、下载、资料库；底部固定“工具”“设置”和账号入口。侧栏右边缘可以拖动加宽（显示文字）或收窄，宽度会记住；左上角的按钮可收起侧栏。窄窗口和手机改为底部导航栏，左上角菜单按钮（或从屏幕左缘右滑）打开与侧栏相同的导航抽屉。

“工具”是一个工具中心：左侧列出下载规则、修复中心、上传压缩和封面预览，右侧是所选工具。手机上没有修复与工具，下载规则和设置从账号面板进入，以全屏页面打开。

侧栏顶部的盾牌按钮显示当前内容分级（全部 / SFW / NSFW），点开即可切换；账号入口打开“账号与偏好”面板，可登录、切换站点、内容分级和主题。

## 首页与内容分级

首页默认依次展示“我的订阅”（需要登录；视频或图片）“热门视频”和“热门图片”。每一栏可以点标题折叠，显示“更新于几分钟前”；热门栏可切换趋势、热度、最新。栏目右侧的“⋮”菜单可刷新该栏或用所选规则下载当前展示的作品；“在搜索页查看更多”跳到搜索页并带上对应的类型、标签或关键词与排序，“我的订阅”的“更多”打开完整的分页网格。

页头“⋮ → 自定义栏目…”（或“设置 → 浏览 → 首页栏目”）打开栏目编辑页：勾选显示、上下移动、编辑与删除，并可把搜索页能搜到的内容放上首页——例如“标签 hmv · 最新”、某位作者的最新作品、某个关键词的结果，每栏可选视频或图片与排序。各栏内容缓存在本地并立即显示，超过“设置 → 存储 → 首页缓存”中设定的时间（默认 15 分钟，0 表示只在手动刷新时检查）才在后台重新检查，切换页面不会触发刷新。

单击封面打开详情页：内置播放器、统计、点赞、作者卡（作者页、程序内订阅、在 Iwara 关注）、简介、可点击的标签、相关推荐和评论；宽窗口里相关推荐在右侧一栏。图片作品显示整组图片。单击 / 双击封面的动作可在“设置 → 浏览 → 点击封面”中调整。首页、搜索和订阅页共用页头的封面大小滑块（Ctrl+= / Ctrl+- / Ctrl+0）。

内容分级同时作用于首页和 Iwara 搜索，选择会保存（Ctrl+Shift+R 循环切换）。`/videos` 与 `/images` 由服务器按 `rating=general|ecchi` 过滤；文本搜索 `/search` 会忽略该参数，因此 SFW / NSFW 时每次取 100 条并在本地过滤，结果不足约 24 条时会继续读取后续页（最多 4 页）。Oreno3D 结果没有分级信息。启动后进入的页面可在“设置 → 系统 → 窗口与启动”中选择，默认首页。

## 快捷键与返回

所有快捷键可在“设置 → 键盘快捷键”中查看和修改：点一下按钮再按新的组合键，Esc 取消，Backspace 清除。默认有：Ctrl+1～Ctrl+9 前往首页、订阅、搜索、下载、修复、资料库、下载规则、设置、工具；Ctrl+, 打开设置；Ctrl+Tab / Ctrl+Shift+Tab 切换页面；Esc 或 Alt+← 返回；Ctrl+Shift+R 切换内容分级；Ctrl+Shift+S 切换 iwara.tv / iwara.ai；Ctrl+Shift+L 切换深色模式；Ctrl+= / Ctrl+- / Ctrl+0 调整封面大小；F11 全屏；Ctrl+Q 退出。

**macOS**：上文的 Ctrl 在 Mac 上一律是 ⌘（Command），并按 Mac 习惯调整了几个默认键：⌃Tab / ⌃⇧Tab 切换页面、⌃⌘F 全屏、⌘W 关闭窗口、⌘M 最小化。设置页直接显示 ⌘ ⌥ ⌃ ⇧ 符号。在触控板上双指向右轻扫即可返回（指针下的内容本身能横向滚动时不触发）。

“返回”（页头的返回箭头、Esc、Alt+←、Mac 触控板右滑、手机返回键）按页面各自记录：在首页打开作品，再用侧栏去搜索页逛一圈回来，返回仍回到首页的列表。侧栏和 Ctrl+1… 只是切换页面，不算一步；从别的页面跳转过来的（如搜索结果的详情、作者页），返回会回到跳转前的页面。

## iwara.tv 与 iwara.ai

两个站点共用同一个账号。按 Ctrl+Shift+S（Mac 上 ⌘⇧S），或在账号面板、“设置 → 浏览 → 站点”中切换（默认 iwara.tv），选择会保存。切换后首页、搜索和“更多”列表改为浏览新站点，首页两站各自缓存；Oreno3D 只收录 iwara.tv，因此在 iwara.ai 下搜索自动改用 Iwara。切换前已显示的作品（详情页、订阅和资料库里的条目、下载任务）仍按原站点打开、播放、点赞和下载。粘贴的链接按自身域名处理。订阅源会记住添加时所在的站点，同一位作者可以在两站分别订阅；订阅页只列出当前站点的订阅，后台定时刷新则会让每个订阅在各自站点检查。

## 下载页

在顶部输入框粘贴一个或多个视频、作者、播放列表或搜索页链接（右侧按钮可直接粘贴剪贴板），点“下载”后会弹出下载面板：列出将要加入的作品、使用的规则，可改选规则并“记住为本页规则”。任务以行显示封面、标题、进度与状态，按“全部 / 下载中 / 排队 / 失败 / 已完成 / 已取消”分类，可按关键词筛选；页头的“⋮”菜单可重试失败、全部取消、恢复已取消和清除已完成，日志按钮打开下载日志。单击已完成的任务按“设置 → 下载 → 下载行为”打开文件夹或播放器。

内置下载器对 8 MiB 以上、服务器支持分段的文件使用多个连接同时下载（“设置 → 下载 → 并发下载 → 每个文件的连接数”，默认 4），中断或失败后按段续传；使用 aria2 时不受影响。

## 订阅页

订阅页只保留作者与播放列表（账号订阅流在首页的“我的订阅”）。宽窗口为左右两栏：左侧是订阅列表（头像、名称、未下载数和新增角标，可搜索、排序），右侧是所选订阅的作品网格，可按标题搜索、按状态筛选、排序和调整封面大小；“下载当前 / 下载选中”经下载面板选择规则，其余操作（下载新增、全选、标为已看、标为已移走、还原已移走、刷新、作者主页、删除订阅）在“⋮”菜单中。两栏间的分隔线可拖动，宽度会记住。手机上是总览卡片：每个订阅一行最近作品，点卡片进入该订阅。页头可添加订阅、全部刷新或导入 Iwara 上关注的作者。

订阅作品的封面会自动缓存到本地：接口常只返回作品存根而没有封面地址时，会查询作品详情补上封面并记住地址。

## 资料库

资料库列出所有下载记录，可在“列表 / 封面”两种视图间切换：宽窗口的列表是表格（按可用宽度自动取舍列，点表头排序），手机是缩略图行。顶部可搜索（标题、作者或全部字段）、按状态筛选、按范围查看（全部、最近下载、未观看、按作者），并可按标签筛选——标签读取视频旁的 NFO（`<文件名>.nfo` 或同目录的 `movie.nfo`），没有 NFO 时用下载时保存的 Iwara 标签。

选中一条记录会在右侧（手机为单独页面）显示详情：封面舞台（可放大查看、前后翻页）、播放按钮（用内置播放器播放本地副本）、“上一个 / 下一个”和“自动连播”（按当前筛选与排序），以及 NFO 的标签、简介和人物。“管理”菜单可标记已看 / 未看、编辑信息、重命名文件、重新定位文件（文件被手动移动后指回新位置）和删除记录。删除记录会立即从列表移除，提示条中 6 秒内可撤销。已下载的视频长按可选择在应用内播放或用外部播放器播放。页头“⋮”菜单可导出 CSV、清理已移走记录等。

## 各页面的下载规则

每个页面使用自己的下载规则，互不影响：在下载面板中改选规则并勾选“记住为本页规则”，只改变该页面；“工具 → 下载规则”顶部的“各页面使用的规则”可以集中设置订阅页、搜索页、视频详情页、首页和下载页链接各用哪条规则。选“跟随默认”的页面使用带 ● 的默认规则（在规则编辑器中“设为默认”）。

规则编辑器上方是规则选择器与新建按钮，下面依次是名称、文件名模板（醒目的示例文件名、可直接编辑的完整模板、“预设”与“插入字段”菜单和“检验”）、元数据筛选（点赞、播放、日期、标签、标题关键词）等；有未保存的修改时切换规则会先询问。标签输入框下方会显示中日英标签候选。

首次启动会添加一条可编辑的“临时下载”规则：保存到下载目录下的 `temp_video/{title}_{id}.mp4`，且不写入下载历史；搜索页和视频详情页默认使用它，订阅页、首页和下载页默认跟随默认规则。临时下载的视频不算“已下载”；详情页播放时仍会先找到这些临时副本，不必再在线播放。

## 作者页、订阅状态与点赞

在搜索结果、首页卡片、详情页或订阅页里选择“作者页”，会打开程序内的作者页（视频 / 图片标签页，可翻页、勾选批量下载）。作者页、订阅详情和详情页的作者卡上有两枚状态标签：“已在程序内订阅 / 未在程序内订阅”和“已在 Iwara 关注 / 未在 Iwara 关注 / 未登录”，旁边的按钮可以在程序内订阅或取消订阅，也可以直接在 Iwara 上关注或取消关注。无法确定 Iwara 账号的 Oreno3D 结果仍可在浏览器打开来源站的作者页。

详情页的“点赞”按钮：登录后可给视频或图片作品点赞，再点一次取消，点赞数即时更新。

## 修复中心

“工具 → 修复”以五步流程批量修改已有视频：选择文件夹 → 命名规则与选项 → 扫描与预览 → 执行 → 结果。默认“原地重命名”保留各文件的原目录，只应用规则的文件名部分；需要按 `{author}/` 等目录规则移动文件时，选择“整理到输出目录”，输出留空则使用扫描根目录。扫描结果逐批显示，每行是状态标签和“原路径 → 目标路径”；点 ✎ 可按 Iwara ID 或链接重新查询。冲突项会跳过，已有同名文件不会被覆盖。只需补录下载记录时，可关闭重命名、封面和 NFO，仅保留加入下载历史。文件夹用“浏览”选择或输入路径（不支持拖放）。

## 搜索

搜索页上方选择数据源（Iwara / Oreno3D）、输入关键词，下方的范围标签切换视频、图片、作者、标签和播放列表，旁边是排序、“筛选”和封面大小。页头的时钟按钮打开搜索记录。

- **关键词与标签**：Iwara 的关键词搜索与标签搜索分别保留输入和排序。关键词支持最新、相关度、播放量和点赞数排序，精确短语可加双引号；留空则浏览列表。“标签”范围下，搜索框下方显示中日英标签候选，点选补全；以逗号分隔多个标签查找同时包含它们的视频。
- **下载标记**：标记来自本地历史和文件是否存在：历史文件仍在时为“本地已下载”，路径失效时为“已移走”，由远端 aria2 保存的为“远端”；Oreno3D 结果取得 Iwara ID 后才判断。
- **作者**：作者结果打开程序内的作者页。

### 搜索后筛选

Iwara 的搜索接口不支持在搜索前限定点赞、播放、时长等条件，因此搜索页提供“后筛选”：结果出来后点“筛选”，在面板中设置点赞数与播放数范围、时长范围（分钟）、发布时间（24 小时内到一年内）、最低点赞率（点赞数 ÷ 播放数）、视频方向（竖屏 / 横屏，按视频分辨率判断）和要排除的标签，并可按点赞、播放、点赞率、时长或发布时间重新排序；留空表示不限。

筛选只作用于当前页已加载的结果，翻页后自动沿用；按钮会显示已设置的条件数，结果摘要显示“找到 N 个 · 筛选后 M 个”。Oreno3D 结果需补全 Iwara 数据后才参与筛选。作者与播放列表结果不支持后筛选。

### Oreno3D 标签桥接

Oreno3D 标签桥接支持单标签直达 `/tags/{id}`，多个标签会在客户端取交集；也可输入 `tag:<id>`、`origin:<id>`、`character:<id>` 或对应的 Oreno3D 实体 URL。结果会解析为正式的 Iwara 视频后再打开或加入队列。Oreno3D 原视频已删除或无法访问时，会通过作者页的其他作品继续寻找 Iwara 作者；找不到可验证账号时保留 Oreno3D 作者页，不根据显示名称猜测账号。标签编号可参阅 [标签索引](../iwara_tags.md)。

## 统一的右键菜单

首页、搜索、订阅、作者页、详情页的相关推荐和资料库的视频菜单使用同一顺序：查看详情 → 播放 → 打开所在文件夹 / 复制文件路径 → 下载 → 在浏览器打开 / 复制链接 → 作者相关 → 本页管理项。桌面上右键弹出菜单，手机上长按打开动作面板（含“选择”）。“播放”会按文件位置显示为“播放本地文件”“播放远端文件”或“在线播放”；已下载的视频另有“在应用内播放 / 用外部播放器播放”。“打开所在文件夹”使用下载历史保存的实际路径；文件已移走或未记录时不显示。

## 下载到 NAS / 远端服务器（aria2）

在“设置 → 下载 → aria2”启用 aria2 RPC 后，打开“aria2 运行在其他设备上（NAS / 服务器）”，填写：

- **aria2 设备上的下载目录**（必填）：aria2 所在机器看到的路径，如 `/volume1/iwara`。下载规则的文件名模板照常生效，视频由远端 aria2 直接写到这里，不会写入本机下载目录，失败时也不会回退到内置下载器。
- **本机挂载路径**（可选）：同一目录在本机的 SMB / NFS 挂载位置，如 `/Volumes/iwara` 或 `Z:\iwara`。填写后可在本机打开文件夹、播放，并把封面和 NFO 写到视频旁边。
- **HTTP 访问地址**（可选）：NAS 上提供该目录的 HTTP 地址，如 `http://nas:8080/iwara`。没有挂载时，可用内置播放器或自定义播放器命令（如 mpv）串流播放。

远端下载的记录会标为“远端”，与“本地已下载”“已移走”分开：不会被当成本机文件，“清理已移走记录”也不会删除这些记录。远端模式下，已在远端的视频会被跳过。封面始终缓存在本机；未挂载时 NFO 会跳过，封面交由远端 aria2 保存到视频旁边。“测试连接”可检查 aria2 是否可达、挂载路径是否可用。手机上推荐用这种方式：手机只负责浏览和提交，文件由那台设备下载，不受手机后台限制。

## 设置

设置按用途分组：外观（主题、语言、字体）、浏览（站点、内容分级、首页栏目、点击封面、播放器）、账号与网络（登录、代理、请求节奏）、下载（画质、下载行为、并发、下载策略、aria2）、存储（下载目录、数据目录、首页缓存、备份 / 恢复 / 日志 / 从旧版导入）、搜索、订阅、系统（窗口与启动、FFmpeg、封面与刷新并发）、键盘快捷键，以及列表底部的“关于”（版本、许可、链接与更新检查）。所有修改立即保存；文本与数字在失焦或回车时保存，代理需点“应用”。

**界面字体**：“设置 → 外观 → 界面字体”默认为“自动”，按当前平台与界面语言选用系统界面字体，例如 Windows 使用 Segoe UI + 微软雅黑 UI，macOS 使用系统字体 + 苹方；日文界面会把日文字体排在中文字体之前。也可以输入本机已安装的任意字体名称，所选字体缺少的字符会依次回退到平台字体和系统默认字体；下方列出当前生效的字体顺序，“自动”按钮可随时恢复默认。

**窗口与启动**（桌面）：“关闭窗口时继续运行”打开时，Windows 关闭窗口后最小化到托盘（单击托盘图标显示，右键可退出），macOS 最小化到程序坞；还可设置开机自动启动与系统通知（下载完成或失败时合并为一条，窗口在前台时显示在应用内）。

## 工具中心

“工具 → 上传压缩 / 封面预览”都调用 ffmpeg：路径留空时自动在 PATH 和常见安装位置（Homebrew、winget、scoop、Chocolatey、程序所在目录）中查找，也可以在“设置 → 系统 → FFmpeg”中手动指定。安装方法：macOS 用 `brew install ffmpeg`，Windows 用 `winget install ffmpeg`。

- **上传压缩**：Iwara 上传要求 H.264 + AAC 编码、MP4 封装、分辨率不低于 720p，大小不超过 300MB（会员 600MB）。选好视频后会先判断需要做什么：已经符合要求的直接提示可上传；只是封装或音频不对的，只转封装（不重新编码画面）；其余的按“上限 ×（1 − 余量）”反推码率重新编码。默认用 x264 两遍编码；硬件编码（VideoToolbox / NVENC / Quick Sync / AMF）更快，若压完超出上限会自动降低码率重压。短边不足 720 的视频会放大到 720p；体积预算撑不起原分辨率时，会自动降到 1080p 或 720p，可在压缩设置中关闭。默认输出到源文件旁的 `原名_iwara.mp4`。
- **封面预览**：上传后 Iwara 会给出 16 张截图供选择封面，推测取自把视频等分成 16 段后每段的正中间（时长 × (2i+1)/32；社区推测，未经官方确认）。载入视频即可看到这 16 张，编号与 Iwara 封面选择里的顺序一致；默认按卡片比例居中裁成 3:2，可关闭以查看完整画面。可用方向键切换，选中后可保存原尺寸截图或复制时间码。压缩完成后可直接对压好的文件计算。

## Android

手机版提供浏览、搜索、订阅、下载与播放；修复中心、工具和打开文件夹等桌面功能隐藏。下载的文件保存在 `Android/data/io.github.moeary.iwaratool/files/Downloads`（文件管理器可见，卸载应用时一并删除）。回到应用时，如果剪贴板里有刚复制的 Iwara 作品或作者链接，会提示打开。所有版本使用同一个签名，新版 APK 直接安装即可覆盖升级。
