## 画面構成

広いウィンドウでは左側のサイドバー上部に 5 つの主要ページ（ホーム、購読、検索、ダウンロード、ライブラリ）、下部に「ツール」「設定」とアカウントが並びます。サイドバーの右端をドラッグすると広げて（ラベル付き）または狭くでき、幅は記憶されます。左上のボタンで折りたためます。狭いウィンドウとスマートフォンでは下部バーになり、左上のメニューボタン（または画面左端からのスワイプ）でサイドバーと同じ構成のドロワーが開きます。

「ツール」はツールハブです。左にダウンロードルール、修復センター、アップロード圧縮、カバープレビューが並び、右に選んだツールが表示されます。スマートフォンには修復とツールがなく、ルールと設定はアカウントパネルから全画面ページとして開きます。

サイドバー上部の盾のボタンは現在のコンテンツ区分（すべて / SFW / NSFW）を示し、押すと切り替えられます。アカウントの項目は「アカウントと設定」パネルを開き、ログイン、サイト、コンテンツ区分、テーマを変更できます。

## ホームとコンテンツ区分

ホームは既定で「購読」（ログインが必要。動画または画像）、「人気動画」、「人気画像」を表示します。欄のタイトルをクリックすると折りたためます。各欄には更新時刻が表示され、人気欄はトレンド・人気・最新を切り替えられます。欄の「⋮」メニューから欄の更新や、表示中の作品を選んだルールでダウンロードできます。「検索で続きを見る」は対応する種類・タグ・キーワード・並び順で検索ページを開き、「購読」の「もっと見る」はページ送りできる全件グリッドを開きます。

ページ上部の「⋮ → 行をカスタマイズ…」（または「設定 → 閲覧 → ホームの欄」）で欄の編集ページを開きます。表示の切り替え、並べ替え、編集、削除ができ、検索ページで見つかるもの（例：「タグ hmv · 最新」、作者の最新作、キーワードの結果）をホームに置けます。欄ごとに動画 / 画像と並び順を選べます。各欄はキャッシュされてすぐ表示され、「設定 → ストレージ → ホームのキャッシュ」の時間（既定 15 分、0 は手動更新時のみ）を過ぎたときだけバックグラウンドで再確認します。ページの切り替えでは更新されません。

カバーをクリックすると詳細ページを開きます。内蔵プレイヤー、統計、いいね、作者カード（作者ページ、アプリ内で購読、Iwara でフォロー）、説明、クリックできるタグ、関連投稿、コメントが並び、広いウィンドウでは関連投稿が右の列に入ります。画像投稿はまとめて表示します。カバーのクリック / ダブルクリックの動作は「設定 → 閲覧 → カバーのクリック」で変えられます。ホーム・検索・購読はページ上部のカバーサイズのスライダーを共有します（Ctrl+= / Ctrl+- / Ctrl+0）。

コンテンツ区分はホームと Iwara 検索に適用され、記憶されます（Ctrl+Shift+R で切り替え）。`/videos` と `/images` はサーバーが `rating=general|ecchi` で絞り込みます。テキスト検索（`/search`）はこの指定を無視するため、SFW / NSFW では毎回 100 件を取得してローカルで絞り込み、約 24 件に満たない間は続きのページ（最大 4 ページ）も読みます。Oreno3D の結果には区分情報がありません。起動時に開くページは「設定 → システム → ウィンドウと起動」で選べます（既定はホーム）。

## ショートカットと戻る

すべてのショートカットは「設定 → キーボードショートカット」で確認・変更できます。ボタンを押して新しいキーを入力し、Esc で取り消し、Backspace で解除します。既定値：Ctrl+1～Ctrl+9 でホーム・購読・検索・ダウンロード・修復・ライブラリ・ルール・設定・ツールへ移動、Ctrl+, で設定、Ctrl+Tab / Ctrl+Shift+Tab でページ切り替え、Esc または Alt+← で戻る、Ctrl+Shift+R でコンテンツ区分、Ctrl+Shift+S で iwara.tv / iwara.ai、Ctrl+Shift+L でダークモード、Ctrl+= / Ctrl+- / Ctrl+0 でカバーサイズ、F11 で全画面、Ctrl+Q で終了。

**macOS**：上記の Ctrl は Mac では ⌘（Command）です。いくつかの既定値は Mac の習慣に合わせています：⌃Tab / ⌃⇧Tab でページ切り替え、⌃⌘F で全画面、⌘W でウィンドウを閉じる、⌘M で最小化。設定には ⌘ ⌥ ⌃ ⇧ の記号で表示されます。トラックパッドで 2 本指で右にスワイプすると戻ります（ポインタの下の内容自体が横にスクロールする場合を除く）。

「戻る」（ページ上部の矢印、Esc、Alt+←、Mac のスワイプ、スマートフォンの戻るキー）はページごとに記録されます。ホームから作品を開き、サイドバーで検索ページを見てから戻ってきても、戻るはホームの一覧に戻ります。サイドバーや Ctrl+1… による切り替えは 1 ステップに数えません。別のページから移動してきた場合（検索結果の詳細、作者ページなど）は、移動元に戻ります。

## iwara.tv と iwara.ai

2 つのサイトは同じアカウントを使います。Ctrl+Shift+S（Mac では ⌘⇧S）、アカウントパネル、または「設定 → 閲覧 → サイト」で切り替えます（既定は iwara.tv）。選択は記憶されます。切り替えるとホーム・検索・「もっと見る」一覧が新しいサイトを表示し、ホームのキャッシュはサイトごとに分かれます。Oreno3D は iwara.tv のみを収録しているため、iwara.ai では検索は Iwara を使います。切り替え前に表示していた作品（開いている詳細ページ、購読やライブラリの項目、ダウンロードタスク）は元のサイトで開き・再生・いいね・ダウンロードします。貼り付けたリンクはそれぞれのドメインで処理します。購読元は追加したときのサイトを記憶するため、同じ作者を両サイトで購読できます。購読ページには現在のサイトの購読だけを表示し、バックグラウンドの定期更新は各購読をそれぞれのサイトで確認します。

## ダウンロード

上部の入力欄に動画・作者・プレイリスト・検索ページの URL を 1 つ以上貼り付け（欄内のボタンでクリップボードから貼り付け）、「ダウンロード」を押します。パネルに追加される作品と使うルールが表示され、そこでルールを変えて「このページのルールとして記憶」もできます。タスクはカバー・タイトル・進捗・状態の行で表示し、「すべて / ダウンロード中 / 待機中 / 失敗 / 完了 / キャンセル済み」で分類、キーワードで絞り込めます。上部の「⋮」メニューで失敗の再試行、すべてキャンセル、キャンセルの取り消し、完了の消去ができ、ログボタンでダウンロードログを開きます。完了したタスクをクリックすると「設定 → ダウンロード → ダウンロードの動作」に従ってフォルダーかプレイヤーを開きます。

内蔵ダウンローダーは、8 MiB を超え Range に対応したサーバーのファイルを複数の接続で同時にダウンロードし（「設定 → ダウンロード → 同時ダウンロード → ファイルごとの接続数」、既定 4）、中断や失敗のあとは部分ごとに再開します。aria2 のダウンロードには影響しません。

## 購読

購読ページは作者とプレイリストのみを扱います（アカウントのフィードはホームの「購読」）。広いウィンドウでは左右 2 列で、左に購読の一覧（アバター、名前、未ダウンロード数、新着バッジ。検索と並べ替え可）、右に選んだ購読の作品グリッド（タイトル検索、状態の絞り込み、並び順、カバーサイズ）が表示されます。「表示中をダウンロード / 選択をダウンロード」はパネルでルールを選び、その他（新着のダウンロード、すべて選択、既読にする、移動済みにする、移動済みを戻す、更新、作者ページ、購読の削除）は「⋮」メニューにあります。列の間の区切り線はドラッグでき、位置は記憶されます。スマートフォンでは各購読の最近の作品を並べた概要から、タップして購読を開きます。上部から購読の追加、すべて更新、Iwara でフォロー中の作者の取り込みができます。

購読作品のカバーは自動でローカルにキャッシュされます。API がカバーのアドレスのない作品情報しか返さない場合は、作品の詳細を取得してカバーを補い、アドレスを記憶します。

## ライブラリ

ライブラリはすべてのダウンロード記録を「リスト / カバー」で表示します。広いウィンドウのリストは表（利用できる幅に応じて列を自動で選び、見出しのクリックで並べ替え）、スマートフォンではサムネイル付きの行です。タイトル・作者・全項目の検索、状態の絞り込み、範囲（すべて、最近のダウンロード、未視聴、作者別）、タグの絞り込みができます。タグは動画の横の NFO（`<ファイル名>.nfo`、または同じフォルダーの `movie.nfo`）から読み、NFO がなければダウンロード時に保存した Iwara のタグを使います。

記録を選ぶと右側（スマートフォンでは別ページ）に詳細が表示されます：カバーステージ（拡大表示、前後へ移動）、再生ボタン（ローカルのファイルを内蔵プレイヤーで再生）、現在の絞り込みと並び順に沿った「前へ / 次へ」と「連続再生」、NFO のタグ・あらすじ・人物。「管理」メニューで既読 / 未読、情報の編集、ファイル名の変更、ファイルの再指定（手動で移動したファイルを指し直す）、記録の削除ができます。削除した記録はすぐ一覧から消え、通知から 6 秒以内なら元に戻せます。ダウンロード済みの動画は長押しでアプリ内か外部プレイヤーでの再生を選べます。上部の「⋮」メニューから CSV の書き出しや移動済み記録の整理などができます。

## ページごとのダウンロードルール

各ページはそれぞれのダウンロードルールを使います。ダウンロードパネルでルールを変えて「このページのルールとして記憶」を選ぶと、そのページだけが変わります。「ツール → ダウンロードルール」上部の「ページごとのルール」で、購読・検索・動画の詳細・ホーム・ダウンロードのリンクに使うルールをまとめて設定できます。「既定に従う」のページは ● の付いた既定ルール（ルールエディターの「既定に設定」）を使います。

ルールエディターの上部にはルールの選択と新規作成ボタンがあり、その下に名前、ファイル名テンプレート（サンプルのファイル名、編集できる完全なテンプレート、「プリセット」「フィールドを挿入」メニュー、「検証」）、メタデータの絞り込み（いいね、再生数、日付、タグ、タイトルのキーワード）などが続きます。未保存の変更があるままルールを切り替えると確認します。タグ欄の下に英中日のタグ候補が表示されます。

初回起動時に、編集できる「一時ダウンロード」ルールが追加されます。保存先はダウンロードフォルダー内の `temp_video/{title}_{id}.mp4` で、履歴には記録しません。検索と動画の詳細は既定でこれを使い、購読・ホーム・ダウンロードは既定ルールに従います。一時ダウンロードは「ダウンロード済み」に数えませんが、詳細ページでの再生ではストリーミングの前にこの一時ファイルを探します。

## 作者ページ、購読状態、いいね

検索結果、ホームのカード、詳細ページ、購読ページで「作者ページ」を選ぶと、アプリ内の作者ページ（動画 / 画像のタブ、ページ送り、選択して一括ダウンロード）を開きます。作者ページ、購読の詳細、詳細ページの作者カードには「アプリで購読中 / アプリで未購読」と「Iwara でフォロー中 / 未フォロー / 未ログイン」の 2 つのバッジがあり、横のボタンでアプリ内の購読と Iwara でのフォローを切り替えられます。Iwara アカウントを特定できない Oreno3D の結果は、ブラウザーで元サイトの作者ページを開けます。

詳細ページの「いいね」ボタンで、ログイン後に動画や画像の投稿にいいね / 取り消しができ、数はすぐ更新されます。

## 修復センター

「ツール → 修復」では既存の動画を 5 つのステップで変更します：フォルダー → 命名ルールとオプション → スキャンとプレビュー → 実行 → 結果。既定の「その場でリネーム」は各ファイルを元のフォルダーに置いたまま、ルールのファイル名部分だけを適用します。`{author}/` などのフォルダー規則で移動するには「出力フォルダーに整理」を選びます（空欄ならスキャンしたフォルダー）。スキャン結果は順次表示され、各行は状態バッジと「元のパス → 移動先のパス」です。✎ で Iwara の ID やリンクから調べ直せます。競合する項目はスキップし、既存のファイルは上書きしません。ダウンロード記録だけを補うには、リネーム・カバー・NFO をオフにして「履歴に追加」だけを残します。フォルダーは「参照」で選ぶかパスを入力します（ドラッグ＆ドロップは非対応）。

## 検索

上部でソース（Iwara / Oreno3D）を選んでキーワードを入力し、その下の範囲チップで動画・画像・作者・タグ・プレイリストを切り替えます。横に並び順、「絞り込み」、カバーサイズがあります。上部の時計ボタンで検索履歴を開きます。

- **キーワードとタグ**：Iwara のキーワード検索とタグ検索は、入力と並び順をそれぞれ保持します。キーワードは最新・関連度・再生数・いいね数で並べ替えられ、完全一致はダブルクォートで囲みます。空欄なら一覧を閲覧します。「タグ」の範囲では入力欄の下に英中日のタグ候補が表示され、選ぶと補完されます。複数のタグをカンマで区切ると、すべてを含む動画を探します。
- **ダウンロードの印**：ローカルの履歴とファイルの有無から判断します。ファイルがあれば「ダウンロード済み」、パスが失われていれば「移動済み」、リモートの aria2 が保存したものは「リモート」です。Oreno3D の結果は Iwara の ID が分かってから判断します。
- **作者**：作者の結果はアプリ内の作者ページを開きます。

### 検索後の絞り込み

Iwara の検索 API はいいね数・再生数・長さなどを事前に絞り込めないため、検索ページでは結果が出たあとに「絞り込み」を押して条件を設定します：いいね数と再生数の範囲、長さ（分）、投稿日時（24 時間以内～1 年以内）、最低いいね率（いいね数 ÷ 再生数）、向き（縦 / 横。動画の解像度で判断）、除外するタグ。いいね・再生数・いいね率・長さ・投稿日時で並べ替えもできます。空欄は制限なしです。

絞り込みは現在のページで読み込んだ結果に適用され、ページを送っても引き継がれます。ボタンには設定した条件の数、概要には「N 件 · 絞り込み後 M 件」と表示されます。Oreno3D の結果は Iwara のデータを補完してから対象になります。作者とプレイリストの結果は絞り込めません。

### Oreno3D タグブリッジ

Oreno3D ブリッジは単一タグなら `/tags/{id}` を直接開き、複数タグはクライアント側で共通部分を取ります。`tag:<id>`、`origin:<id>`、`character:<id>` や対応する Oreno3D の URL も使えます。結果は正式な Iwara の動画に解決してから開いたりキューに追加したりします。Oreno3D の元動画が削除されている・アクセスできない場合は、作者の他の作品から Iwara の作者を探します。確認できるアカウントが見つからなければ、表示名から推測せず Oreno3D の作者ページのままにします。タグ ID は [タグ一覧](../iwara_tags.md) を参照してください。

## 共通の操作メニュー

ホーム、検索、購読、作者ページ、詳細ページの関連投稿、ライブラリの動画メニューは同じ順序です：詳細を表示 → 再生 → フォルダーを開く / ファイルパスをコピー → ダウンロード → ブラウザーで開く / リンクをコピー → 作者関連 → そのページの管理項目。デスクトップでは右クリック、スマートフォンでは長押しで操作パネル（「選択」付き）を開きます。「再生」はファイルの場所に応じて「ローカルファイルを再生」「リモートファイルを再生」「オンライン再生」と表示され、ダウンロード済みの動画には「アプリ内で再生 / 外部プレイヤーで再生」もあります。「フォルダーを開く」はダウンロード履歴に保存された実際のパスを使い、ファイルが移動済みまたは未記録のときは表示されません。

## NAS / リモートサーバーへのダウンロード（aria2）

「設定 → ダウンロード → aria2」で aria2 RPC を有効にし、「aria2 は別のデバイス（NAS / サーバー）で動作」をオンにして次を入力します：

- **aria2 デバイス上の保存先**（必須）：aria2 のマシンから見たパス（例：`/volume1/iwara`）。ファイル名テンプレートはそのまま使われ、動画はリモートの aria2 がここに直接書き込みます。ローカルの保存先には書き込まず、失敗しても内蔵ダウンローダーには切り替えません。
- **ローカルのマウントパス**（任意）：同じフォルダーをこの PC に SMB / NFS でマウントした場所（例：`/Volumes/iwara`、`Z:\iwara`）。指定するとこの PC でフォルダーを開いたり再生したりでき、カバーと NFO を動画の横に書き込みます。
- **HTTP アドレス**（任意）：NAS がそのフォルダーを公開する HTTP アドレス（例：`http://nas:8080/iwara`）。マウントがなくても内蔵プレイヤーやカスタムプレイヤーのコマンド（mpv など）でストリーミング再生できます。

リモートのダウンロードは「リモート」と表示され、「ダウンロード済み」「移動済み」とは区別されます。ローカルのファイルとして扱わず、「移動済み記録の整理」でも削除しません。リモートモードでは NAS にある動画はスキップします。カバーは常にこの PC にキャッシュし、マウントがない場合は NFO をスキップしてカバーはリモートの aria2 が動画の横に保存します。「接続テスト」で aria2 への接続とマウントパスを確認できます。スマートフォンではこの構成がおすすめです：スマートフォンは閲覧と送信だけを行い、ダウンロードは別のデバイスが行うため、バックグラウンドの制限を受けません。

## 設定

設定は用途別のグループです：外観（テーマ、言語、フォント）、閲覧（サイト、コンテンツ区分、ホームの欄、カバーのクリック、プレイヤー）、アカウントとネットワーク（ログイン、プロキシ、リクエスト間隔）、ダウンロード（画質、動作、同時実行、ポリシー、aria2）、ストレージ（保存先、データフォルダー、ホームのキャッシュ、バックアップ / 復元 / ログ / 旧バージョンからの取り込み）、検索、購読、システム（ウィンドウと起動、FFmpeg、カバー読み込みと更新の同時実行）、キーボードショートカット、一覧の下部に「情報」（バージョン、ライセンス、リンク、更新確認）。変更はすぐ保存されます。テキストと数値は欄を離れるか Enter で保存し、プロキシは「適用」が必要です。

**UI フォント**：「設定 → 外観 → UI フォント」は既定で「自動」で、プラットフォームと UI の言語に合わせてシステムの UI フォントを選びます（Windows は Segoe UI + Microsoft YaHei UI、macOS はシステムフォント + PingFang など）。日本語 UI では日本語フォントを中国語フォントより前に置きます。インストール済みの任意のフォント名を入力することもでき、足りない文字はプラットフォームとシステムのフォントで補います。下に使用中のフォントの順序が表示され、「自動」ボタンで既定に戻せます。

**ウィンドウと起動**（デスクトップ）：「ウィンドウを閉じても実行を続ける」をオンにすると、Windows では閉じたときにトレイへ（アイコンのクリックで表示、右クリックで終了）、macOS では Dock へ最小化します。ログイン時の自動起動とシステム通知もここで設定します（完了・失敗したダウンロードは 1 つの通知にまとめ、ウィンドウが前面にあるときはアプリ内に表示）。

## ツール

「ツール → アップロード圧縮 / カバープレビュー」は ffmpeg を使います。パスが空欄なら PATH と一般的なインストール先（Homebrew・winget・scoop・Chocolatey・アプリと同じフォルダー）から探し、見つからなければ「設定 → システム → FFmpeg」で指定します。インストールは macOS なら `brew install ffmpeg`、Windows なら `winget install ffmpeg` です。

- **アップロード圧縮**：Iwara のアップロードは H.264 + AAC、MP4、720p 以上、300 MB 以下（会員は 600 MB）が条件です。動画を選ぶとまず必要な処理を判定します。条件を満たしていればそのままアップロードでき、コンテナや音声だけが違う場合は映像を再エンコードせずに再多重化し、それ以外は「上限 ×（1 − 余裕）」から求めたビットレートで再エンコードします。既定は x264 の 2 パスで、ハードウェアエンコード（VideoToolbox / NVENC / Quick Sync / AMF）は高速ですが、上限を超えたらビットレートを下げて再圧縮します。短辺が 720 未満の動画は 720p に拡大し、サイズの予算で元の解像度を保てない場合は 1080p または 720p に下げます（圧縮設定でオフにできます）。出力は元ファイルの横の `元の名前_iwara.mp4` です。
- **カバープレビュー**：アップロード後に Iwara はカバー候補として 16 枚のスクリーンショットを示します。動画を 16 等分した各区間の中央（長さ × (2i+1)/32。コミュニティの推測で公式未確認）から取られているようです。動画を読み込むと 16 枚が Iwara の選択画面と同じ順番で表示されます。既定ではカードと同じ 3:2 に中央で切り抜き、オフにすると全体を確認できます。矢印キーで移動し、原寸のスクリーンショットの保存やタイムコードのコピーができます。圧縮後は完成したファイルで計算できます。

## Android

スマートフォン版は閲覧・検索・購読・ダウンロード・再生に対応し、修復センター、ツール、フォルダーを開くなどのデスクトップ機能は表示しません。ダウンロードしたファイルは `Android/data/io.github.moeary.iwaratool/files/Downloads` に保存されます（ファイルマネージャーで見え、アンインストール時に削除されます）。アプリに戻ったとき、クリップボードにコピーしたばかりの Iwara の作品や作者のリンクがあれば開くか確認します。すべてのリリースが同じ署名を持つため、新しい APK をそのままインストールすれば上書き更新できます。
