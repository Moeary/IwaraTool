## ホームとコンテンツ区分

ホームは最初のページで、既定では「購読中の更新」（要ログイン、動画／画像）「人気の動画」「人気の画像」を表示します。各行はタイトルをクリックして折りたためて、最終更新の目安と個別の更新ボタンがあり、人気の行ではトレンド・人気・新着を切り替えられます。見出しの鉛筆アイコン（Ctrl+E）または「設定 → ホーム」で欄をカスタマイズでき、追加・削除・並べ替え・一時的な非表示のほか、検索ページで探せるもの（例:「タグ hmv・新着」の欄、特定の作者の最新作、キーワード検索の結果）をホームに置けます。各欄で動画／画像と並び順を選び、「初期設定に戻す」で元の3欄に戻せます。「新着」の欄が欲しいときは「人気・新着リスト」の欄を追加して並び順に「新着」を選びます。各欄はディスクに保存されてすぐ表示され、「設定 → ホーム」の時間（既定15分、0は手動更新のみ）を過ぎたときだけバックグラウンドでサイトに再確認し、投稿が実際に変わったときだけカードを更新します。ページを切り替えても更新は走らず、カードを選択中に新着が来ても「新着あり — 表示」のリンクで待機し、選択を乱しません。アカウントのフィード・各並び順タブ・各コンテンツ区分は別々にキャッシュされ、ログイン状態が変わるとアカウント関連のみ破棄されます。カードをクリックするとアプリ内で詳細を開き、カバーと再生、統計、「いいね」ボタン、作者（作者ページ・作品・購読状態）、説明、タグ、関連、コメントを確認できます。画像投稿は全画像を表示します。人気／カスタム欄の「検索ページで見る」は、対応する種類・タグ／キーワード・並び順で検索ページを開き（作者の欄はアプリ内の作者ページを開きます）、ページ送り・リスト表示・まとめて追加は検索ページで行います。「購読中の更新」の「もっと見る」はページ送り付きの一覧を開き、カードを選択して選んだルールでまとめてキューに追加できます。動画の行には「表示中をダウンロード」もあります。ホーム・検索・購読・その一覧は見出しの「カバーサイズ」スライダーを共有します（検索ページの「列数」ボックスはこれに統合されました）。読み込み中はプレースホルダーを表示し、カバーはフェードイン、ホバーで軽く拡大します。カードを右クリックすると、再生・保存・ブラウザーで開く・作者ページを開く・作者の作品を表示・作者を購読ができます。

右上の「コンテンツ」（すべて／SFW／NSFW）はホームと Iwara 検索に適用され、設定は保存されます。`/videos` と `/images` はサーバー側で `rating=general|ecchi` により絞り込みます。テキスト検索 `/search` はこのパラメーターを無視するため、SFW／NSFW のときは 100 件ずつ取得してローカルで絞り込み、約 24 件に満たなければ後続ページ（最大 4 ページ）を続けて読み込みます。「次へ」は最後に読んだページの続きから進みます。Oreno3D の結果には区分がないため、その場合は選択欄を隠します。検索の「画像」はキーワード空欄でも閲覧でき、結果の右クリック「詳細を表示」でホームの詳細ページを開けます。サイドバーの順序はホーム、購読、検索、ダウンロードハブ、修復、履歴で、Ctrl+1〜Ctrl+6 に対応します（ルールと設定は Ctrl+7・Ctrl+8。設定で変更可能）。起動時に開くページは「設定 → ウィンドウと起動 → 起動時に表示するページ」で選べます（既定はホーム）。詳細ページは広い画面でプレイヤーを利用可能な幅まで広げ、関連投稿を右側の列に移します。他のページ（購読など）から詳細を開いた場合、「戻る」で元のページに戻ります。

## キーボードショートカット

F1 でいつでも全ショートカットを確認できます（現在のページのものは全体用の直後）。すべて「設定 → キーボードショートカット」で変更できます。主なもの：Ctrl+K クイック検索、Ctrl+Tab／Ctrl+Shift+Tab ページ切り替え、Ctrl+Alt+V クリップボードのリンクを貼り付けて保存、Ctrl+Shift+O 保存フォルダーを開く、Ctrl+Shift+R コンテンツ区分の切り替え、Ctrl+=／Ctrl+-／Ctrl+0 カバーサイズ、Ctrl+Shift+L ダークモード、F11 全画面。ホーム：Ctrl+E 欄のカスタマイズ、F5 更新、Ctrl+Home／Ctrl+End 先頭／末尾へ、Ctrl+Shift+↑／↓ すべての欄を折りたたみ／展開。投稿を開いているとき：Ctrl+L いいね、Ctrl+P 再生、Ctrl+D 保存、Ctrl+O ブラウザーで開く、Ctrl+Shift+C リンクをコピー、Ctrl+Shift+A 作者ページ、Esc 戻る。検索：Alt+←／→ ページ送り、Ctrl+Shift+G グリッド／リスト、Ctrl+Shift+F 検索欄の折りたたみ。購読：Alt+← 一覧へ戻る、Ctrl+A 全選択、Esc 選択解除、Ctrl+Shift+T 概要／表形式。

カバーのグリッドはキーボードでも操作できます。クリックするか Tab で入ってから、矢印キー／Home／End／PageUp／PageDown でカーソルを移動、Enter で開く、Space で選択、Ctrl+A で全選択、Esc で解除、メニューキーまたは Shift+F10 で右クリックメニューを開けます。

## 購読

購読ページは作者とプレイリストのみを扱います（アカウントフィードはホームの「購読中の更新」に置き換わり、古いアカウントフィード項目は表示されません）。既定の「概要」は購読ごとの大きな行で、アイコン・名前・新着／未保存数と最新カバーの帯を表示します。カバーをクリックで詳細ページ、右クリックで詳細・再生・保存・記録、行または「すべて表示」をクリックすると、検索のようなカードグリッドでその作者／プレイリストの全動画を表示し、状態の絞り込み、タイトル検索、選択したルールでの一括保存ができます。購読を開くと、表示中ページのカバーが取得キューの先頭に入り（概要の数百枚の後ろで待たされません）、状態行に「カバー読み込み中（残り n）」と表示され、失敗したカバーは再表示か「更新」で再試行されます。見出しの「表形式」で従来のリスト／カバー表示も使え、そのカバー表示も同じカバーサイズスライダーを使います。

タスクセンターの上部に、実行中タスクの合計ダウンロード速度が表示されるようになりました。

## 作者ページ・購読状態・いいね

検索結果・ホームのカード・詳細ページ・購読ページの「作者ページを開く」は、既定でアプリ内の作者ページを開きます。アプリで購読済みの作者は購読グリッド、それ以外の作者は Iwara 上の作品（動画／画像、ページ送り・一括保存付き）を表示します。作者ページと購読グリッドの上部には2つの状態タグ「アプリで購読中／アプリでは未購読」と「Iwaraでフォロー中／Iwaraでは未フォロー／未ログイン」（後者は Iwara へのログインが必要）があり、アプリ内での購読・解除と Iwara サイト上でのフォロー・解除をその場で行えます。詳細ページの作者カードにも同じバーと「作者ページ」ボタンがあります。Iwara アカウントを特定できない Oreno3D の結果は「作者ページをブラウザーで開く」から元サイトを開けます。

詳細ページには「いいね」ボタンも追加されました。ログイン中は動画・画像投稿にいいねでき、もう一度押すと取り消し、件数はすぐ更新されます。未ログインの場合はログインを促します。

## 修復センター

既存動画の名前をまとめて変更するには、修復センターでフォルダーと命名ルールを選び、検索します。既定の「元の場所で名前変更」は各動画の親フォルダーを維持し、ルールのファイル名部分のみを適用します。`{author}/` などのディレクトリ規則で移動する場合は、「出力先へ整理」を選択してください。出力欄が空なら検索元のルートを使用します。実行前に変更元と変更先のフルパスを確認してください。競合する項目はスキップし、既存の同名ファイルは上書きしません。履歴だけを登録する場合は、名前変更・カバー・NFO を無効にして履歴への追加のみを有効にします。

## 検索の保存状態

検索の保存状態はローカル履歴とファイルの存在に基づきます。記録されたファイルがまだ存在する場合は「ローカル保存済み」、パスが無効な場合は「移動済み」と表示します。Oreno3D の結果は Iwara ID の解決後に判定します。作者の作品表示では購読を追加せず、「購読に追加して移動」では該当する作者の購読元を選択します。

## Oreno3D 作者のフォールバック

Oreno3D の元動画が削除済み・閲覧不可の場合、自動補完では作者ページの別作品から Iwara 作者を探します。オンデマンドモードでは作者操作で検索します。アカウントを確認できなくても Oreno3D 作者ページは保持し、表示名から Iwara アカウントを推測しません。

## Iwara のキーワード検索とタグ検索

Iwara のキーワード検索とタグ検索は入力と並び順を別々に保持します。キーワードは新着・関連度・再生数・いいね順に対応し、完全一致の語句は二重引用符で囲めます。空欄なら動画一覧を表示します。タグは中日英の候補または正確な翻訳名を入力し、複数をカンマで区切ると、すべてのタグを含む動画を検索します。並び順とページ送りはサーバーの結果を使用し、失敗理由も表示します。

## Oreno3D タグブリッジ

Oreno3D のタグブリッジでは、タグスコープの単一ラベルを `/tags/{id}` へ直接検索でき、複数ラベルはクライアント側で共通結果を求めます。`tag:<id>`、`origin:<id>`、`character:<id>`、Oreno3D エンティティ URL にも対応し、このブリッジでは Oreno3D の動画検索とタグ検索に対応しています。作者またはプレイリストの結果は Iwara ライブ API に切り替えてください。結果は開く／キューへ追加する前に正式な Iwara 動画へ解決されます。タグ ID は [タグ索引](../iwara_tags.md) を参照してください。

## 購読カバーのキャッシュ

購読カバーは自動的にローカルへ保存されます。特定の作者のカバーを事前にキャッシュする場合は、まずその購読元を選択して動画一覧を更新し、「更新操作 → 購読元の全カバーをキャッシュ」を使用します。この操作は、その購読元に登録されているすべての動画が対象で、現在のフィルターや一覧／カバー表示の影響を受けません。動画本体はダウンロードしません。再度実行すると既存のカバーを再利用し、欠けている項目を再試行します。初回のカバー取得にはネットワーク接続が必要です。完了時には成功数と失敗数が表示されます。
