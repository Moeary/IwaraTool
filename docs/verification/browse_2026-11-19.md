# 视频方向筛选与文件夹菜单验收

环境：Apple Silicon macOS，项目 Pixi Python 3.11、PySide6 6.6.2。桌面验收使用 Computer Use 操作实际 MainWindow，数据来自隔离的离线样例。

## 验收结果

| 操作 | 结果 |
| --- | --- |
| 32 条结果中选择竖屏并应用 | 显示 8 条竖屏，排除横屏、方形和未知分辨率 |
| 竖屏条件下翻到第二页 | 条件保留，第二页仍显示 8 条竖屏 |
| 改为横屏并应用 | 显示 8 条横屏 |
| 切换列表视图 | 保留横屏条件，列表显示对应的 8 条视频 |
| 清除条件并应用 | 恢复当前页全部 32 条，包含方形和未知分辨率 |
| 搜索结果右键打开所在文件夹 | Finder 打开 `old_account`，其中包含 `Portrait Starlight Dance_demo000.mp4` |
| 订阅总览卡片右键打开所在文件夹 | 关闭上一步 Finder 窗口后重新执行，正确打开同一实际保存目录 |

验收中方向下拉菜单曾触发 Qt 在销毁临时菜单时的焦点崩溃，最终改为弹窗内的三个直接选项。上述方向切换和应用操作均在改动后重新通过。

自动回归覆盖分辨率归一化、边界与无效值、组合筛选、Oreno3D 数据补全后更新网格和列表、弹窗条件读写与清除、旧目录定位，以及菜单打开后文件被移走的提示。最终执行 `pixi run test`：共 945 项，通过 943 项，跳过 2 项。

另用项目同款 cloudscraper 读取 Iwara 公开列表，确认真实响应的 `file` 对象提供 `width` 和 `height`。界面验收未使用真实账号或个人下载历史。Windows 和 Linux 的原生界面交互尚未实测。

## 复现方式

```shell
pixi run test
pixi run python scripts/verify_browse.py --lang zh
```

验收脚本会打印临时目录，所有 HTTP 请求均由 `demo_fixture` 回答。样例共 64 条，每四条依次为竖屏、横屏、方形、未知分辨率；`demo000` 在 `old_account` 中有本地视频，`demo001` 的历史路径不存在。可从搜索页重复上述操作。语言可选 `en`、`zh`、`ja`。脚本保留临时目录供检查，退出后可自行清理。
