- **Material 3 的三种规范布局：**
  - 列表-详情（list-detail）
  - 辅助窗格（supporting pane）
  - 信息流（feed）

## 统一规则（各页共用）

1. **一页一个主操作。** 页头右侧只放一个主按钮（实心）加一个“更多”菜单；次要操作进菜单或行内。
2. **两种骨架。**
   - 宽窗口（内容区 ≥ 840）用列表-详情或辅助窗格。
   - 窄窗口用“列表 → 详情页”。
   - 分隔线一律可拖动并记住宽度（`components/split_handle.py`）。
3. **筛选条一行。** 搜索框（可伸缩）+ 下拉筛选 + 排序 + 视图 / 封面大小，放在内容上方。
4. **状态只用徽章**（`status_badge`），不用整行彩色块；数字计数放在标签或徽章里。
5. **空状态** 统一为“图标 + 一句话 + 一个按钮”。

## 逐页提案

| 页面 | 现状问题 | 提案 | 优先级 |
| --- | --- | --- | --- |
| 首页 | 各栏目标题行按钮多（折叠、⋯、查看更多），未登录时“我的订阅”占一整块 | 栏目标题行只留“查看更多 ›”，折叠与栏目设置并入一个 ⋯；未登录时“我的订阅”缩成一行提示条；栏目间距收紧，首屏多露一行卡片 | 中 |
| 搜索 | 来源、范围、排序、筛选、封面大小挤在两行；分页器在右上 | 第一行“来源 + 搜索框 + 搜索”；第二行范围标签；排序 / 筛选 / 封面大小收进右侧一个“视图”按钮的弹出面板；分页改为滚动到底自动加载（保留页码跳转在“更多”） | 中 |
| 订阅 | 已精简；左栏只有名称与未下载数 | 左栏加“仅看有新作品”开关和分组（作者 / 播放列表）；右栏“下载当前”在有选择时变为“下载选中”并显示数量（已做） | 低 |
| 下载 | 每行右侧两个图标按钮，排队项没有封面；顶部输入框与标签分两行 | 列表-详情：右侧窗格显示选中任务的详情（进度、速度、文件位置、日志、重试 / 打开文件夹）；行内只留进度与一个“⋯”；排队项用作品标题占位；状态标签与筛选合成一行 | 高 |
| 资料库 | 表格列多、操作分散 | 表格保留，选中一行时右侧辅助窗格显示记录详情与操作（打开、定位、重新下载、删除），代替弹出面板；视图切换（表格 / 列表 / 封面）放进筛选条右端 | 中 |
| 视频详情 | 1280 宽时播放器占满首屏，信息与相关作品都在下面 | 宽窗口（≥ 1200）改为辅助窗格：左侧播放器 + 标题 / 操作 / 简介，右侧固定宽度的“相关作品”纵列；操作条合并为“播放 · 下载 · 点赞 · ⋯（浏览器打开、复制链接）” | 高 |
| 作者页 | 与订阅右栏重复的订阅 / 关注按钮组 | 头部：头像、名称、统计、一个“订阅 / 已订阅”主按钮 + ⋯（Iwara 关注、浏览器打开）；下方作品网格与订阅右栏共用同一个组件 | 中 |
| 工具中心 | 已完成 | 后续：修复的五步条在窄窗口改为“第 n / 5 步”紧凑标题 | 低 |
| 设置 | 已完成分组 | 后续：顶部加设置搜索框（按卡片标题过滤） | 低 |

## 建议顺序

1. 视频详情的辅助窗格布局与下载页的列表-详情（使用最频繁、收益最大）。
2. 搜索筛选条与首页栏目标题行的精简。
3. 资料库辅助窗格、作者页头部。
4. 其余低优先级项。

每一项完成后都要：更新 `docs/flet_ui_plan.md` 第 10 节“功能取舍”表，跑 `test-flet`，并用 `flet_viewports.py` 截取浅色 / 深色与手机尺寸的截图检查。
